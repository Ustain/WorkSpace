## 1. 爬楼梯（70）

**难度**：简单

**题目描述**：你正在爬楼梯。需要 `n` 阶你才能到达楼顶。每次你可以爬 `1` 或 `2` 个台阶。你有多少种不同的方法可以爬到楼顶呢？

**原题链接**：https://leetcode.cn/problems/climbing-stairs/

**解题思路**：
- `f(n) = f(n-1) + f(n-2)`（最后一步跨 1 或 2 阶），即斐波那契数列
- 用两个变量滚动递推，空间 O(1)
- 时间复杂度 O(n)

**题解代码（Python）**：
```python
class Solution:
    def climbStairs(self, n: int) -> int:
        prev, cur = 0, 1
        for _ in range(n):
            prev, cur = cur, prev + cur
        return cur
```

**题解代码（Java）**：
```java
class Solution {
    public int climbStairs(int n) {
        int prev = 0, cur = 1;
        for (int i = 0; i < n; i++) {
            int next = prev + cur;
            prev = cur;
            cur = next;
        }
        return cur;
    }
}
```

**题解代码（Go）**：
```go
func climbStairs(n int) int {
    prev, cur := 0, 1
    for i := 0; i < n; i++ {
        prev, cur = cur, prev+cur
    }
    return cur
}
```

## 2. 杨辉三角（118）

**难度**：简单

**题目描述**：给定一个非负整数 `numRows`，生成「杨辉三角」的前 `numRows` 行。在「杨辉三角」中，数三角尖端的两个数是 1，每个数是它左上方和右上方的数的和。

**原题链接**：https://leetcode.cn/problems/pascals-triangle/

**解题思路**：
- 第 i 行有 i 个数，首尾为 1；中间元素 = 上一行左右两数之和
- 逐行构建，时间复杂度 O(numRows²)，空间 O(1)（不计输出）

**题解代码（Python）**：
```python
class Solution:
    def generate(self, numRows: int) -> List[List[int]]:
        ans = []
        for i in range(numRows):
            row = [1] * (i + 1)
            for j in range(1, i):
                row[j] = ans[i - 1][j - 1] + ans[i - 1][j]
            ans.append(row)
        return ans
```

**题解代码（Java）**：
```java
class Solution {
    public List<List<Integer>> generate(int numRows) {
        List<List<Integer>> ans = new ArrayList<>();
        for (int i = 0; i < numRows; i++) {
            List<Integer> row = new ArrayList<>();
            for (int j = 0; j <= i; j++) {
                if (j == 0 || j == i) row.add(1);
                else row.add(ans.get(i - 1).get(j - 1) + ans.get(i - 1).get(j));
            }
            ans.add(row);
        }
        return ans;
    }
}
```

**题解代码（Go）**：
```go
func generate(numRows int) [][]int {
    ans := [][]int{}
    for i := 0; i < numRows; i++ {
        row := make([]int, i+1)
        row[0], row[i] = 1, 1
        for j := 1; j < i; j++ {
            row[j] = ans[i-1][j-1] + ans[i-1][j]
        }
        ans = append(ans, row)
    }
    return ans
}
```

## 3. 打家劫舍（198）

**难度**：中等

**题目描述**：你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金。影响你偷窃的唯一制约因素就是相邻的房屋装有相互连通的防盗系统，如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警。给定一个代表每个房屋存放金额的非负整数数组，计算你不触动警报装置的情况下，一夜之内能够偷窃到的最高金额。

**原题链接**：https://leetcode.cn/problems/house-robber/

**解题思路**：
- `f(i) = max(f(i-1), f(i-2) + nums[i])`：不偷第 i 家（沿用前 i-1 家最优）或偷第 i 家（必须放弃第 i-1 家）
- 两个变量滚动即可，空间 O(1)
- 时间复杂度 O(n)

**题解代码（Python）**：
```python
class Solution:
    def rob(self, nums: List[int]) -> int:
        prev, cur = 0, 0  # f(i-2), f(i-1)
        for num in nums:
            prev, cur = cur, max(cur, prev + num)
        return cur
```

**题解代码（Java）**：
```java
class Solution {
    public int rob(int[] nums) {
        int prev = 0, cur = 0;
        for (int num : nums) {
            int next = Math.max(cur, prev + num);
            prev = cur;
            cur = next;
        }
        return cur;
    }
}
```

**题解代码（Go）**：
```go
func rob(nums []int) int {
    prev, cur := 0, 0 // f(i-2), f(i-1)
    for _, num := range nums {
        next := cur
        if prev+num > next {
            next = prev + num
        }
        prev, cur = cur, next
    }
    return cur
}
```

## 4. 完全平方数（279）

**难度**：中等

**题目描述**：给你一个整数 `n`，返回 和为 `n` 的完全平方数的最少数量。完全平方数 是一个整数，其值等于另一个整数的平方；换句话说，其值等于一个整数自乘的积。例如，`1`、`4`、`9` 和 `16` 都是完全平方数，而 `3` 和 `11` 不是。

**原题链接**：https://leetcode.cn/problems/perfect-squares/

**解题思路**：
- 完全背包型 DP：`f(i) = min(f(i - j²)) + 1`，j² ≤ i
- f(0) = 0，从小到大递推
- 时间复杂度 O(n·√n)，空间 O(n)

**题解代码（Python）**：
```python
class Solution:
    def numSquares(self, n: int) -> int:
        f = [0] + [float('inf')] * n
        for i in range(1, n + 1):
            j = 1
            while j * j <= i:
                f[i] = min(f[i], f[i - j * j] + 1)
                j += 1
        return f[n]
```

**题解代码（Java）**：
```java
class Solution {
    public int numSquares(int n) {
        int[] f = new int[n + 1];
        Arrays.fill(f, 1, n + 1, Integer.MAX_VALUE);
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j * j <= i; j++) {
                f[i] = Math.min(f[i], f[i - j * j] + 1);
            }
        }
        return f[n];
    }
}
```

**题解代码（Go）**：
```go
func numSquares(n int) int {
    const inf = math.MaxInt32
    f := make([]int, n+1)
    for i := 1; i <= n; i++ {
        f[i] = inf
        for j := 1; j*j <= i; j++ {
            if v := f[i-j*j] + 1; v < f[i] {
                f[i] = v
            }
        }
    }
    return f[n]
}
```

## 5. 零钱兑换（322）

**难度**：中等

**题目描述**：给你一个整数数组 `coins`，表示不同面额的硬币；以及一个整数 `amount`，表示总金额。计算并返回可以凑成总金额所需的 最少的硬币个数。如果没有任何一种硬币组合能组成总金额，返回 `-1`。你可以认为每种硬币的数量是无限的。

**原题链接**：https://leetcode.cn/problems/coin-change/

**解题思路**：
- 完全背包：`f(i) = min(f(i - coin) + 1)`，对每个金额尝试所有面额
- f(0) = 0，不可达状态用无穷大表示
- 时间复杂度 O(amount × coins)，空间 O(amount)

**题解代码（Python）**：
```python
class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        f = [0] + [float('inf')] * amount
        for coin in coins:
            for i in range(coin, amount + 1):
                f[i] = min(f[i], f[i - coin] + 1)
        return f[amount] if f[amount] != float('inf') else -1
```

**题解代码（Java）**：
```java
class Solution {
    public int coinChange(int[] coins, int amount) {
        int[] f = new int[amount + 1];
        Arrays.fill(f, 1, amount + 1, Integer.MAX_VALUE);
        for (int coin : coins) {
            for (int i = coin; i <= amount; i++) {
                if (f[i - coin] != Integer.MAX_VALUE) {
                    f[i] = Math.min(f[i], f[i - coin] + 1);
                }
            }
        }
        return f[amount] == Integer.MAX_VALUE ? -1 : f[amount];
    }
}
```

**题解代码（Go）**：
```go
func coinChange(coins []int, amount int) int {
    const inf = math.MaxInt32
    f := make([]int, amount+1)
    for i := 1; i <= amount; i++ {
        f[i] = inf
    }
    for _, coin := range coins {
        for i := coin; i <= amount; i++ {
            if f[i-coin]+1 < f[i] {
                f[i] = f[i-coin] + 1
            }
        }
    }
    if f[amount] == inf {
        return -1
    }
    return f[amount]
}
```

## 6. 单词拆分（139）

**难度**：中等

**题目描述**：给你一个字符串 `s` 和一个字符串列表 `wordDict` 作为字典。请你判断是否可以利用字典中出现的单词拼接出 `s`。注意：不要求字典中出现的单词全部都使用，并且字典中的单词可以重复使用。

**原题链接**：https://leetcode.cn/problems/word-break/

**解题思路**：
- `f(i)` 表示 s 前 i 个字符能否被字典拼出；转移：`f(i) = ∃ j < i, f(j) && s[j..i) ∈ dict`
- 用哈希集合加速子串查询，枚举 j 只需考虑字典中最长单词长度
- 时间复杂度 O(n · m · L)，空间 O(n)

**题解代码（Python）**：
```python
class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        words = set(wordDict)
        max_len = max(map(len, words))
        n = len(s)
        f = [True] + [False] * n
        for i in range(1, n + 1):
            for j in range(max(0, i - max_len), i):
                if f[j] and s[j:i] in words:
                    f[i] = True
                    break
        return f[n]
```

**题解代码（Java）**：
```java
class Solution {
    public boolean wordBreak(String s, List<String> wordDict) {
        Set<String> words = new HashSet<>(wordDict);
        int maxLen = 0;
        for (String w : words) maxLen = Math.max(maxLen, w.length());
        int n = s.length();
        boolean[] f = new boolean[n + 1];
        f[0] = true;
        for (int i = 1; i <= n; i++) {
            for (int j = Math.max(0, i - maxLen); j < i; j++) {
                if (f[j] && words.contains(s.substring(j, i))) {
                    f[i] = true;
                    break;
                }
            }
        }
        return f[n];
    }
}
```

**题解代码（Go）**：
```go

    maxLen := 0
    for _, w := range wordDict {
        words[w] = true
        if len(w) > maxLen {
            maxLen = len(w)
        }
    }

                f[i] = true
                break
            }
        }
    }
    return f[n]
```

## 7. 最长递增子序列（300）

**难度**：中等

**题目描述**：给你一个整数数组 `nums`，找到其中最长严格递增子序列的长度。子序列 是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。

**原题链接**：https://leetcode.cn/problems/longest-increasing-subsequence/

**解题思路**：
- 基础 DP：`f(i) = max(f(j)) + 1`（j < i 且 nums[j] < nums[i]），时间 O(n²)
- 进阶（贪心+二分，O(n log n)）：维护 tails 数组，tails[k] 是长度为 k+1 的递增子序列的最小结尾；每个新元素二分查找替换或追加位置
- 时间复杂度 O(n log n)，空间 O(n)

**题解代码（Python）**：
```python
class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        tails = []  # tails[k]: 长度为 k+1 的 LIS 的最小结尾
        for num in nums:
            # 二分找第一个 >= num 的位置
            left, right = 0, len(tails)
            while left < right:
                mid = (left + right) // 2
                if tails[mid] < num:
                    left = mid + 1
                else:
                    right = mid
            if left == len(tails):
                tails.append(num)
            else:
                tails[left] = num
        return len(tails)
```

**题解代码（Java）**：
```java
class Solution {
    public int lengthOfLIS(int[] nums) {
        int[] tails = new int[nums.length];
        int size = 0;
        for (int num : nums) {
            int left = 0, right = size;
            while (left < right) {
                int mid = (left + right) >>> 1;
                if (tails[mid] < num) left = mid + 1;
                else right = mid;
            }
            tails[left] = num;
            if (left == size) size++;
        }
        return size;
    }
}
```


## 8. 乘积最大子数组（152）

**难度**：中等

**题目描述**：给你一个整数数组 `nums`，请你找出数组中乘积最大的非空连续子数组（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。

**原题链接**：https://leetcode.cn/problems/maximum-product-subarray/

**解题思路**：
- 与最大子数组和不同：负数乘负数会翻正，需同时维护以 i 结尾的最大乘积 fmax 和最小乘积 fmin
- 转移：`fmax(i) = max(nums[i], fmax(i-1)*nums[i], fmin(i-1)*nums[i])`，fmin 同理取 min
- 时间复杂度 O(n)，空间 O(1)

**题解代码（Python）**：
```python
class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        fmax = fmin = ans = nums[0]
        for num in nums[1:]:
            if num < 0:
                fmax, fmin = fmin, fmax  # 乘负数后大小互换
            fmax = max(num, fmax * num)
            fmin = min(num, fmin * num)
            ans = max(ans, fmax)
        return ans
```

**题解代码（Java）**：
```java
class Solution {
    public int maxProduct(int[] nums) {
        int fmax = nums[0], fmin = nums[0], ans = nums[0];
        for (int i = 1; i < nums.length; i++) {
            int num = nums[i];
            if (num < 0) {
                int tmp = fmax;
                fmax = fmin;
                fmin = tmp;
            }
            fmax = Math.max(num, fmax * num);
            fmin = Math.min(num, fmin * num);
            ans = Math.max(ans, fmax);
        }
        return ans;
    }
}
```

**题解代码（Go）**：

## 9. 分割等和子集（416）

**难度**：中等

**题目描述**：给你一个 只包含正整数 的 非空 数组 `nums`。请你判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。

**原题链接**：https://leetcode.cn/problems/partition-equal-subset-sum/

**解题思路**：
- 转化为 0-1 背包：能否从数组中选出若干数使其和恰为 total / 2
- 总和为奇数直接 false；`f[j]` 表示和 j 能否凑出，倒序遍历容量（一维滚动数组防止重复选取）
- 时间复杂度 O(n × target)，空间 O(target)

**题解代码（Python）**：
```python
class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        total = sum(nums)
        if total % 2:
            return False
        target = total // 2
        f = [False] * (target + 1)
        f[0] = True
        for num in nums:
            for j in range(target, num - 1, -1):  # 倒序：0-1 背包
                f[j] = f[j] or f[j - num]
            if f[target]:
                return True
        return f[target]
```

**题解代码（Java）**：
```java
class Solution {
    public boolean canPartition(int[] nums) {
        int total = 0;
        for (int num : nums) total += num;
        if (total % 2 != 0) return false;
        int target = total / 2;
        boolean[] f = new boolean[target + 1];
        f[0] = true;
        for (int num : nums) {
            for (int j = target; j >= num; j--) {
                f[j] = f[j] || f[j - num];
            }
            if (f[target]) return true;
        }
        return f[target];
    }
}
```

**题解代码（Go）**：

## 10. 最长有效括号（32）

**难度**：困难

**题目描述**：给你一个只包含 `'('` 和 `')'` 的字符串，找出最长的包含有效括号的子串的长度。

**原题链接**：https://leetcode.cn/problems/longest-valid-parentheses/

**解题思路**：
- DP：`f(i)` 表示以 i 结尾的最长有效括号长度
- 当 `s[i] == ')'`：若 `s[i-1] == '('`，则 `f(i) = f(i-2) + 2`；若 `s[i-f(i-1)-1] == '('`，则 `f(i) = f(i-1) + 2 + f(i - f(i-1) - 2)`（接上更前面一段）
- 栈解法也可：栈底存"最后一个未匹配位置"作分界
- 时间复杂度 O(n)，空间 O(n)

**题解代码（Python）**：
```python
class Solution:
    def longestValidParentheses(self, s: str) -> int:
        n = len(s)
        f = [0] * n
        ans = 0
        for i in range(1, n):
            if s[i] == ')':
                if s[i - 1] == '(':
                    f[i] = (f[i - 2] if i >= 2 else 0) + 2
                elif i - f[i - 1] - 1 >= 0 and s[i - f[i - 1] - 1] == '(':
                    f[i] = f[i - 1] + 2
                    if i - f[i - 1] - 2 >= 0:
                        f[i] += f[i - f[i - 1] - 2]
                ans = max(ans, f[i])
        return ans
```

**题解代码（Java）**：
```java

                }
                ans = Math.max(ans, f[i]);
            }
        }
        return ans;
    }
}
```
