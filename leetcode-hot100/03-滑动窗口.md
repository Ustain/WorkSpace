# 滑动窗口（2题）

## 1. 无重复字符的最长子串（3）

**难度**：中等

**题目描述**：给定一个字符串 `s`，请你找出其中不含有重复字符的 最长子串 的长度。

**原题链接**：https://leetcode.cn/problems/longest-substring-without-repeating-characters/

**解题思路**：
- 滑动窗口 `[left, right]`，用哈希集合记录窗口内的字符
- right 右移时若遇到重复字符，不断右移 left 并从集合中删除字符，直到无重复
- 每一步用窗口长度更新答案
- 时间复杂度 O(n)（每个字符最多进出窗口各一次），空间复杂度 O(|Σ|)

**题解代码（Python）**：
```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        window = set()
        left = ans = 0
        for right, ch in enumerate(s):
            while ch in window:
                window.remove(s[left])
                left += 1
            window.add(ch)
            ans = max(ans, right - left + 1)
        return ans
```

**题解代码（Java）**：
```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        Set<Character> window = new HashSet<>();
        int left = 0, ans = 0;
        for (int right = 0; right < s.length(); right++) {
            char ch = s.charAt(right);
            while (window.contains(ch)) {
                window.remove(s.charAt(left));
                left++;
            }
            window.add(ch);
            ans = Math.max(ans, right - left + 1);
        }
        return ans;
    }
}
```

**题解代码（Go）**：
```go
func lengthOfLongestSubstring(s string) int {
    window := map[byte]bool{}
    left, ans := 0, 0
    for right := 0; right < len(s); right++ {
        for window[s[right]] {
            window[s[left]] = false
            left++
        }
        window[s[right]] = true
        if right-left+1 > ans {
            ans = right - left + 1
        }
    }
    return ans
}
```

## 2. 找到字符串中所有字母异位词（438）

**难度**：中等

**题目描述**：给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的 异位词 子串，返回这些子串的起始索引。不考虑答案输出的顺序。

**原题链接**：https://leetcode.cn/problems/find-all-anagrams-in-a-string/

**解题思路**：
- 定长滑动窗口：窗口大小固定为 `len(p)`，维护窗口内各字母计数
- 窗口右移时加入新字符、移出左端字符，比较窗口计数与 p 的计数是否相等
- 优化：用 diff 变量记录计数不等的字母种数，避免每次全量比较 26 个字母
- 时间复杂度 O(n + |Σ|)，空间复杂度 O(|Σ|)

**题解代码（Python）**：
```python
class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        n, m = len(s), len(p)
        if n < m:
            return []
        cnt_p = Counter(p)
        cnt_w = Counter(s[:m])
        ans = []
        if cnt_w == cnt_p:
            ans.append(0)
        for right in range(m, n):
            cnt_w[s[right]] += 1
            cnt_w[s[right - m]] -= 1
            if cnt_w[s[right - m]] == 0:
                del cnt_w[s[right - m]]
            if cnt_w == cnt_p:
                ans.append(right - m + 1)
        return ans
```

**题解代码（Java）**：
```java
class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        int n = s.length(), m = p.length();
        List<Integer> ans = new ArrayList<>();
        if (n < m) return ans;
        int[] cntP = new int[26], cntW = new int[26];
        for (int i = 0; i < m; i++) {
            cntP[p.charAt(i) - 'a']++;
            cntW[s.charAt(i) - 'a']++;
        }
        if (Arrays.equals(cntP, cntW)) ans.add(0);
        for (int right = m; right < n; right++) {
            cntW[s.charAt(right) - 'a']++;
            cntW[s.charAt(right - m) - 'a']--;
            if (Arrays.equals(cntP, cntW)) ans.add(right - m + 1);
        }
        return ans;
    }
}
```

**题解代码（Go）**：
```go
func findAnagrams(s string, p string) []int {
    n, m := len(s), len(p)
    ans := []int{}
    if n < m {
        return ans
    }
    var cntP, cntW [26]int
    for i := 0; i < m; i++ {
        cntP[p[i]-'a']++
        cntW[s[i]-'a']++
    }
    if cntP == cntW {
        ans = append(ans, 0)
    }
    for right := m; right < n; right++ {
        cntW[s[right]-'a']++
        cntW[s[right-m]-'a']--
        if cntP == cntW {
            ans = append(ans, right-m+1)
        }
    }
    return ans
}
```
