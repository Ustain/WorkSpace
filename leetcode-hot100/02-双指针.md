# 双指针（4题）

## 1. 移动零（283）

**难度**：简单

**题目描述**：给定一个数组 `nums`，编写一个函数将所有 `0` 移动到数组的末尾，同时保持非零元素的相对顺序。要求必须在不复制数组的情况下原地对数组进行操作。

**原题链接**：https://leetcode.cn/problems/move-zeroes/

**解题思路**：
- 快慢双指针：slow 指向下一个非零元素应放的位置，fast 向右扫描
- fast 遇到非零数就与 slow 交换并右移 slow，保证 slow 左边全是非零数且相对顺序不变
- 时间复杂度 O(n)，空间复杂度 O(1)

**题解代码（Python）**：
```python
class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        slow = 0
        for fast in range(len(nums)):
            if nums[fast] != 0:
                nums[slow], nums[fast] = nums[fast], nums[slow]
                slow += 1
```

**题解代码（Java）**：
```java
class Solution {
    public void moveZeroes(int[] nums) {
        int slow = 0;
        for (int fast = 0; fast < nums.length; fast++) {
            if (nums[fast] != 0) {
                int tmp = nums[slow];
                nums[slow] = nums[fast];
                nums[fast] = tmp;
                slow++;
            }
        }
    }
}
```

**题解代码（Go）**：

## 2. 盛最多水的容器（11）

**难度**：中等

**题目描述**：给定一个长度为 `n` 的整数数组 `height`。有 `n` 条垂线，第 `i` 条线的两个端点是 `(i, 0)` 和 `(i, height[i])`。找出其中的两条线，使得它们与 x 轴共同构成的容器可以容纳最多的水，返回容器可以储存的最大水量。

**原题链接**：https://leetcode.cn/problems/container-with-most-water/

**解题思路**：
- 左右双指针从两端开始，面积为 `min(h[l], h[r]) * (r - l)`
- 移动较短的那一侧：因为水量由短板决定，移动长板宽度变小、高度不会更高，面积只会更小；移动短板才可能让面积变大
- 每次移动后更新最大面积，直到指针相遇
- 时间复杂度 O(n)，空间复杂度 O(1)

**题解代码（Python）**：
```python
class Solution:
    def maxArea(self, height: List[int]) -> int:
        l, r, ans = 0, len(height) - 1, 0
        while l < r:
            ans = max(ans, min(height[l], height[r]) * (r - l))
            if height[l] < height[r]:
                l += 1
            else:
                r -= 1
        return ans
```

**题解代码（Java）**：
```java
class Solution {
    public int maxArea(int[] height) {
        int l = 0, r = height.length - 1, ans = 0;
        while (l < r) {
            ans = Math.max(ans, Math.min(height[l], height[r]) * (r - l));
            if (height[l] < height[r]) l++;
            else r--;
        }
        return ans;
    }
}
```

**题解代码（Go）**：
```go
func maxArea(height []int) int {
    l, r, ans := 0, len(height)-1, 0
    for l < r {
        area := height[l]
        if height[r] < area {
            area = height[r]
        }
        if w := r - l; area*w > ans {
            ans = area * w
        }
        if height[l] < height[r] {
            l++
        } else {
            r--
        }
    }
    return ans
}
```

## 3. 三数之和（15）

**难度**：中等

**题目描述**：给你一个整数数组 `nums`，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k`，同时还满足 `nums[i] + nums[j] + nums[k] == 0`。返回所有和为 0 且不重复的三元组。

**原题链接**：https://leetcode.cn/problems/3sum/

**解题思路**：
- 先排序，固定第一个数 i，用左右双指针在 `[i+1, n-1]` 区间找两数之和为 `-nums[i]`
- 三处去重：i 与前一个数相同则跳过；找到答案后左右指针各自跳过相同值
- 和大于 0 时右指针左移，和小于 0 时左指针右移
- 时间复杂度 O(n²)，空间复杂度 O(log n)（排序栈）

**题解代码（Python）**：
```python
class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        nums.sort()
        n, res = len(nums), []
        for i in range(n - 2):
            if nums[i] > 0:
                break
            if i > 0 and nums[i] == nums[i - 1]:
                continue
            l, r = i + 1, n - 1
            while l < r:
                total = nums[i] + nums[l] + nums[r]
                if total == 0:
                    res.append([nums[i], nums[l], nums[r]])
                    while l < r and nums[l] == nums[l + 1]:
                        l += 1
                    while l < r and nums[r] == nums[r - 1]:
                        r -= 1
                    l += 1
                    r -= 1
                elif total < 0:
                    l += 1
                else:
                    r -= 1
        return res
```

**题解代码（Java）**：

```java
                    r--;

                    l++;
                } else {
                    r--;
                }
            }
        }
        return res;
    }
}
```

## 4. 接雨水（42）

**难度**：困难

**题目描述**：给定 `n` 个非负整数表示每个宽度为 1 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

**原题链接**：https://leetcode.cn/problems/trapping-rain-water/

**解题思路**：
- 每个位置能接的水为 `min(左边最高, 右边最高) - height[i]`
- 双指针法：维护 leftMax、rightMax，较小的一侧决定了该侧指针位置的水位
  - 若 `height[left] < height[right]`，则 left 位置的水由 leftMax 决定（右边必有更大的挡着），累加后右移 left；反之处理右侧
- 时间复杂度 O(n)，空间复杂度 O(1)（也可用前后缀数组 O(n) 空间实现）

**题解代码（Python）**：
```python
class Solution:
    def trap(self, height: List[int]) -> int:
        left, right = 0, len(height) - 1
        leftMax = rightMax = 0
        ans = 0
        while left < right:
            leftMax = max(leftMax, height[left])
            rightMax = max(rightMax, height[right])
            if height[left] < height[right]:
                ans += leftMax - height[left]
                left += 1
            else:
                ans += rightMax - height[right]
                right -= 1
        return ans
```

**题解代码（Java）**：
```java
class Solution {
    public int trap(int[] height) {
        int left = 0, right = height.length - 1;
        int leftMax = 0, rightMax = 0, ans = 0;
        while (left < right) {
            leftMax = Math.max(leftMax, height[left]);
            rightMax = Math.max(rightMax, height[right]);
            if (height[left] < height[right]) {
                ans += leftMax - height[left];
                left++;
            } else {
                ans += rightMax - height[right];
                right--;
            }
        }
        return ans;
    }
}
```
