## 1. 搜索插入位置（35）

**难度**：简单

**题目描述**：给定一个排序数组和一个目标值，在数组中找到目标值，并返回其索引。如果目标值不存在于数组中，返回它将会被按顺序插入的位置。请必须使用时间复杂度为 `O(log n)` 的算法。

**原题链接**：https://leetcode.cn/problems/search-insert-position/

**解题思路**：
- 标准二分找"第一个大于等于 target 的下标"（lower_bound）
- `nums[mid] < target` 时左边界右移，否则右边界左移；最终 left 即答案
- 时间复杂度 O(log n)，空间 O(1)

**题解代码（Python）**：
```python
class Solution:
    def searchInsert(self, nums: List[int], target: int) -> int:
        left, right = 0, len(nums)
        while left < right:
            mid = (left + right) // 2
            if nums[mid] < target:
                left = mid + 1
            else:
                right = mid
        return left
```

## 2. 搜索二维矩阵（74）

**难度**：中等

**题目描述**：给你一个满足下述两条属性的 `m x n` 整数矩阵：每行中的整数从左到右按非严格递增顺序排列；每行的第一个整数大于前一行的最后一个整数。给你一个整数 `target`，如果 `target` 在矩阵中，返回 `true`；否则，返回 `false`。

**原题链接**：https://leetcode.cn/problems/search-a-2d-matrix/

**解题思路**：
- 矩阵按行拼接后是一个整体有序的一维数组，可直接对 `0 ~ m*n-1` 二分
- 下标映射：`mid → matrix[mid // n][mid % n]`
- 时间复杂度 O(log(mn))，空间 O(1)

**题解代码（Python）**：
```python
class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        m, n = len(matrix), len(matrix[0])
        left, right = 0, m * n - 1
        while left <= right:
            mid = (left + right) // 2
            val = matrix[mid // n][mid % n]
            if val == target:
                return True
            elif val < target:
                left = mid + 1
            else:
                right = mid - 1
        return False
```

**题解代码（Java）**：
```java
class Solution {

            if (val == target) return true;
            else if (val < target) left = mid + 1;

        }
        return false;
    }
}
```

## 3. 在排序数组中查找元素的第一个和最后一个位置（34）

**难度**：中等

**题目描述**：给你一个按照非递减顺序排列的整数数组 `nums`，和一个目标值 `target`。请你找出给定目标值在数组中的开始位置和结束位置。如果数组中不存在目标值 `target`，返回 `[-1, -1]`。你必须设计并实现时间复杂度为 `O(log n)` 的算法解决此问题。

**原题链接**：https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array/

**解题思路**：
- 两次二分求 lower_bound 和 upper_bound（第一个大于 target 的位置），区间为 `[lb, ub)`
- lower_bound：找第一个 `>= target` 的下标；upper_bound：找第一个 `> target` 的下标（即第一个 `>= target+1`）
- 校验 `lb < n && nums[lb] == target` 判断是否存在
- 时间复杂度 O(log n)，空间 O(1)

**题解代码（Python）**：
```python
class Solution:
    def searchRange(self, nums: List[int], target: int) -> List[int]:
        lb = bisect.bisect_left(nums, target)   # 第一个 >= target
        ub = bisect.bisect_right(nums, target)  # 第一个 > target
        if lb == ub:
            return [-1, -1]
        return [lb, ub - 1]
```

**题解代码（Java）**：
```java
class Solution {

        int ub = lowerBound(nums, target + 1);

        return new int[]{lb, ub - 1};
    }

    // 第一个 >= target 的下标
    private int lowerBound(int[] nums, int target) {
        int left = 0, right = nums.length;
        while (left < right) {
            int mid = (left + right) >>> 1;
            if (nums[mid] < target) left = mid + 1;
            else right = mid;
        }
        return left;
    }
}
```

## 4. 搜索旋转排序数组（33）

**难度**：中等

**题目描述**：整数数组 `nums` 按升序排列，数组中的值 互不相同。在传递给函数之前，`nums` 在预先未知的某个下标 `k`（`0 <= k < nums.length`）上进行了旋转。给你 旋转后 的数组 `nums` 和一个整数 `target`，如果 `nums` 中存在这个目标值 `target`，则返回它的下标，否则返回 `-1`。你必须设计一个时间复杂度为 `O(log n)` 的算法解决此问题。

**原题链接**：https://leetcode.cn/problems/search-in-rotated-sorted-array/

**解题思路**：
- 旋转后数组一半有序一半无序：mid 把数组分成两半，其中必有连续有序的一段
- 先判断哪半有序（比较 nums[left] 与 nums[mid]），再判断 target 是否落在有序段内
  - `[left, mid]` 有序：`nums[left] <= target < nums[mid]` 则 target 在左半，否则去右半
  - `[mid, right]` 有序：`nums[mid] < target <= nums[right]` 则 target 在右半，否则去左半
- 时间复杂度 O(log n)，空间 O(1)

**题解代码（Python）**：
```python
class Solution:
    def search(self, nums: List[int], target: int) -> int:
        left, right = 0, len(nums) - 1
        while left <= right:
            mid = (left + right) // 2
            if nums[mid] == target:
                return mid
            if nums[left] <= nums[mid]:  # 左半有序
                if nums[left] <= target < nums[mid]:
                    right = mid - 1
                else:
                    left = mid + 1
            else:  # 右半有序
                if nums[mid] < target <= nums[right]:
                    left = mid + 1
                else:
                    right = mid - 1
        return -1
```

**题解代码（Java）**：

```java
        }
        return -1;
    }
}
```

## 5. 寻找旋转排序数组中的最小值（153）

**难度**：中等

**题目描述**：已知一个长度为 `n` 的数组，预先按照升序排列，经由 1 到 n 次 旋转 后，得到输入数组。给你一个元素值 互不相同 的数组 `nums`，它原来是一个升序排列的数组，并按上述情形进行了多次旋转。请你找出并返回数组中的 最小元素。你必须设计一个时间复杂度为 `O(log n)` 的算法解决此问题。

**原题链接**：https://leetcode.cn/problems/find-minimum-in-rotated-sorted-array/

**解题思路**：
- 二分比较 `nums[mid]` 与 `nums[right]`：
  - `nums[mid] > nums[right]`：最小值在 mid 右侧（旋转点在右），`left = mid + 1`
  - `nums[mid] < nums[right]`：最小值在 mid 及其左侧，`right = mid`
- 收敛到 left == right 即最小值。与 right 而非 left 比较，才能正确处理未旋转的情况
- 时间复杂度 O(log n)，空间 O(1)

**题解代码（Python）**：
```python
class Solution:
    def findMin(self, nums: List[int]) -> int:
        left, right = 0, len(nums) - 1
        while left < right:
            mid = (left + right) // 2
            if nums[mid] > nums[right]:
                left = mid + 1
            else:
                right = mid
        return nums[left]
```

## 6. 寻找两个正序数组的中位数（4）

**难度**：困难

**题目描述**：给定两个大小分别为 `m` 和 `n` 的正序（从小到大）数组 `nums1` 和 `nums2`。请你找出并返回这两个正序数组的 中位数。算法的时间复杂度应该为 `O(log (m+n))`。

**原题链接**：https://leetcode.cn/problems/median-of-two-sorted-arrays/

**解题思路**：
- 问题转化为"找第 k 小的数"（k = (m+n+1)/2 和 (m+n+2)/2，奇偶两次取平均）
- 第 k 小：每次在两数组各取前 k/2 个元素比较两者第 k/2 个值，较小一方的前 k/2 个元素不可能包含第 k 小，可以整体排除，k 减半递归
- 处理边界：某数组为空直接取另一数组第 k 小；k==1 取两数组头部较小值
- 时间复杂度 O(log(m+n))，空间 O(1)

**题解代码（Python）**：
```python
class Solution:
    def findMedianSortedArrays(self, nums1: List[int], nums2: List[int]) -> float:
        def getKth(nums1, i, nums2, j, k):
            if i == len(nums1):
                return nums2[j + k - 1]
            if j == len(nums2):
                return nums1[i + k - 1]
            if k == 1:
                return min(nums1[i], nums2[j])
            half = k // 2
            new_i = min(i + half, len(nums1)) - 1
            new_j = min(j + half, len(nums2)) - 1
            if nums1[new_i] <= nums2[new_j]:
                return getKth(nums1, new_i + 1, nums2, j, k - (new_i + 1 - i))
            else:
                return getKth(nums1, i, nums2, new_j + 1, k - (new_j + 1 - j))

        total = len(nums1) + len(nums2)
        left = getKth(nums1, 0, nums2, 0, (total + 1) // 2)
        right = getKth(nums1, 0, nums2, 0, (total + 2) // 2)
        return (left + right) / 2
```

**题解代码（Java）**：

```java
        int left = getKth(nums1, 0, nums2, 0, (total + 1) / 2);
        int right = getKth(nums1, 0, nums2, 0, (total + 2) / 2);
        return (left + right) / 2.0;
    }

    private int getKth(int[] nums1, int i, int[] nums2, int j, int k) {
        if (i == nums1.length) return nums2[j + k - 1];
        if (j == nums2.length) return nums1[i + k - 1];
        if (k == 1) return Math.min(nums1[i], nums2[j]);
        int half = k / 2;
        int newI = Math.min(i + half, nums1.length) - 1;
        int newJ = Math.min(j + half, nums2.length) - 1;
        if (nums1[newI] <= nums2[newJ]) {
            return getKth(nums1, newI + 1, nums2, j, k - (newI + 1 - i));
        } else {
            return getKth(nums1, i, nums2, newJ + 1, k - (newJ + 1 - j));
        }
    }
}
```
