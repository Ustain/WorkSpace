# 哈希（3题）

## 1. 两数之和（1）

**难度**：简单

**题目描述**：给定一个整数数组 `nums` 和整数目标值 `target`，请在该数组中找出和为目标值 `target` 的那两个整数，并返回它们的数组下标。可以假设每种输入只会对应一个答案，且同一个元素不能使用两遍。

**原题链接**：https://leetcode.cn/problems/two-sum/

**解题思路**：
- 暴力法双重循环为 O(n²)，用哈希表把"查找 complement"降到 O(1)
- 遍历数组，先查 `target - nums[i]` 是否已在哈希表中，在则直接返回两个下标；否则把当前数存入哈希表
- 时间复杂度 O(n)，空间复杂度 O(n)

**题解代码（Python）**：
```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        hashtable = {}
        for i, num in enumerate(nums):
            if target - num in hashtable:
                return [hashtable[target - num], i]
            hashtable[num] = i
        return []
```

**题解代码（Java）**：
```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> map = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            if (map.containsKey(target - nums[i])) {
                return new int[]{map.get(target - nums[i]), i};
            }
            map.put(nums[i], i);
        }
        return new int[0];
    }
}
```

**题解代码（Go）**：
```go
func twoSum(nums []int, target int) []int {
    hashtable := map[int]int{}
    for i, num := range nums {
        if j, ok := hashtable[target-num]; ok {
            return []int{j, i}
        }
        hashtable[num] = i
    }
    return nil
}
```

## 2. 字母异位词分组（49）

**难度**：中等

**题目描述**：给你一个字符串数组，请你将 字母异位词 组合在一起。字母异位词是由重新排列源单词的所有字母得到的新单词。

**原题链接**：https://leetcode.cn/problems/group-anagrams/

**解题思路**：
- 互为异位词的字符串排序后结果相同，可作为哈希表的 key
- 遍历字符串，将每个字符串排序后的结果作为 key，原字符串加入对应分组
- 也可用 26 位字母计数数组转成字符串作 key，避免排序的 O(klogk)
- 时间复杂度 O(nk·logk)（n 为字符串数，k 为最大长度）

**题解代码（Python）**：
```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        groups = defaultdict(list)
        for s in strs:
            key = ''.join(sorted(s))
            groups[key].append(s)
        return list(groups.values())
```

**题解代码（Java）**：
```java
class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> groups = new HashMap<>();
        for (String s : strs) {
            char[] arr = s.toCharArray();
            Arrays.sort(arr);
            String key = new String(arr);
            groups.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
        }
        return new ArrayList<>(groups.values());
    }
}
```

**题解代码（Go）**：
```go
func groupAnagrams(strs []string) [][]string {
	m := make(map[string][]string)
	res := make([][]string, 0)

	for _, str := range strs {
		s := []byte(str)
		slices.Sort(s)
		key := string(s)
		m[key] = append(m[key], str)
	}

	for _, group := range m {
		res = append(res, group)
	}

	return res
}
```

## 3. 最长连续序列（128）

**难度**：中等

**题目描述**：给定一个未排序的整数数组 `nums`，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。请设计并实现时间复杂度为 O(n) 的算法解决此问题。

**原题链接**：https://leetcode.cn/problems/longest-consecutive-sequence/

**解题思路**：
- 将所有数字放入哈希集合，O(n) 建集合 + O(1) 查询
- 只从"序列起点"开始枚举：若 `num - 1` 不在集合中，说明 num 是某段连续序列的开头，向后数 num+1、num+2… 更新长度
- 每个数字最多被访问两次，总时间复杂度 O(n)

**题解代码（Python）**：
```python
class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        num_set = set(nums)
        longest = 0
        for num in num_set:
            if num - 1 not in num_set:  # 只从序列起点开始
                cur = num
                length = 1
                while cur + 1 in num_set:
                    cur += 1
                    length += 1
                longest = max(longest, length)
        return longest
```

**题解代码（Java）**：
```java
class Solution {
    public int longestConsecutive(int[] nums) {
        Set<Integer> numSet = new HashSet<>();
        for (int num : nums) numSet.add(num);
        int longest = 0;
        for (int num : numSet) {
            if (!numSet.contains(num - 1)) { // 只从序列起点开始
                int cur = num, length = 1;
                while (numSet.contains(cur + 1)) {
                    cur++;
                    length++;
                }
                longest = Math.max(longest, length);
            }
        }
        return longest;
    }
}
```

**题解代码（Go）**：
```go
func longestConsecutive(nums []int) int {
    numSet := map[int]bool{}
    for _, num := range nums {
        numSet[num] = true
    }
    longest := 0
    for num := range numSet {
        if !numSet[num-1] { // 只从序列起点开始
            cur, length := num, 1
            for numSet[cur+1] {
                cur++
                length++
            }
            if length > longest {
                longest = length
            }
        }
    }
    return longest
}
```
