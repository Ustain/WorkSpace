## 1. 相交链表（160）

**难度**：简单

**题目描述**：给你两个单链表的头节点 `headA` 和 `headB`，请你找出并返回两个单链表相交的起始节点。如果两个链表不存在相交节点，返回 `null`。整个链式结构中不存在环。函数返回结果后，链表必须保持原结构。

**原题链接**：https://leetcode.cn/problems/intersection-of-two-linked-lists/

**解题思路**：
- 双指针浪漫解法：pA 走完 A 走 B，pB 走完 B 走 A，两者走过的总长度相同（a + c + b）
- 若相交，会在交点相遇；若不相交，会同时到达 null
- 时间复杂度 O(m + n)，空间复杂度 O(1)

**题解代码（Python）**：
```python
class Solution:
    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> Optional[ListNode]:
        pA, pB = headA, headB
        while pA is not pB:
            pA = pA.next if pA else headB
            pB = pB.next if pB else headA
        return pA
```

**题解代码（Java）**：
```java
public class Solution {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        ListNode pA = headA, pB = headB;
        while (pA != pB) {
            pA = (pA == null) ? headB : pA.next;
            pB = (pB == null) ? headA : pB.next;
        }
        return pA;
    }
}
```

**题解代码（Go）**：
```go
func getIntersectionNode(headA, headB *ListNode) *ListNode {
    pA, pB := headA, headB
    for pA != pB {
        if pA != nil {
            pA = pA.Next
        } else {
            pA = headB
        }
        if pB != nil {
            pB = pB.Next
        } else {
            pB = headA
        }
    }
    return pA
}
```

## 2. 反转链表（206）

**难度**：简单

**题目描述**：给你单链表的头节点 `head`，请你反转链表，并返回反转后的链表。

**原题链接**：https://leetcode.cn/problems/reverse-linked-list/

**解题思路**：
- 迭代：三指针 prev/cur/next，每次把 cur.next 指向 prev，然后整体右移
- 递归：`reverse(head)` 等价于先反转 `head.next` 之后的链表，再把 head 接到尾部
- 时间复杂度 O(n)，迭代空间 O(1)

**题解代码（Python）**：
```python
class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        prev, cur = None, head
        while cur:
            nxt = cur.next
            cur.next = prev
            prev = cur
            cur = nxt
        return prev
```

**题解代码（Java）**：
```java
class Solution {
    public ListNode reverseList(ListNode head) {
        ListNode prev = null, cur = head;
        while (cur != null) {
            ListNode nxt = cur.next;
            cur.next = prev;
            prev = cur;
            cur = nxt;
        }
        return prev;
    }
}
```

**题解代码（Go）**：
```go
func reverseList(head *ListNode) *ListNode {
    var prev *ListNode
    cur := head
    for cur != nil {
        nxt := cur.Next
        cur.Next = prev
        prev = cur
        cur = nxt
    }
    return prev
}
```

## 3. 回文链表（234）

**难度**：简单

**题目描述**：给你一个单链表的头节点 `head`，请你判断该链表是否为回文链表。如果链表是回文的，返回 `true`；否则，返回 `false`。进阶：能否用 O(n) 时间复杂度和 O(1) 空间复杂度解决此题？

**原题链接**：https://leetcode.cn/problems/palindrome-linked-list/

**解题思路**：
- 快慢指针找中点 → 反转后半段 → 前后半段逐一比较
- 快指针每次走 2 步，慢指针每次走 1 步，快指针到尾时慢指针在中点（奇数长度正好在中间）
- 比较完后（可选）恢复链表结构
- 时间复杂度 O(n)，空间复杂度 O(1)

**题解代码（Python）**：
```python
class Solution:
    def isPalindrome(self, head: Optional[ListNode]) -> bool:
        # 快慢指针找中点
        slow = fast = head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
        # 反转后半段
        prev, cur = None, slow
        while cur:
            cur.next, prev, cur = prev, cur, cur.next
        # 前后半段比较
        p1, p2 = head, prev
        while p2:
            if p1.val != p2.val:
                return False
            p1, p2 = p1.next, p2.next
        return True
```

**题解代码（Java）**：
```java
class Solution {

        ListNode slow = head, fast = head;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }
        ListNode prev = null, cur = slow;
        while (cur != null) {
            ListNode nxt = cur.next;
            cur.next = prev;
            prev = cur;
            cur = nxt;
        }
        ListNode p1 = head, p2 = prev;
        while (p2 != null) {
            if (p1.val != p2.val) return false;
            p1 = p1.next;
            p2 = p2.next;
        }
        return true;
    }
}
```


## 4. 环形链表（141）

**难度**：简单

**题目描述**：给你一个链表的头节点 `head`，判断链表中是否有环。如果链表中存在环，则返回 `true`；否则，返回 `false`。

**原题链接**：https://leetcode.cn/problems/linked-list-cycle/

**解题思路**：
- Floyd 判圈：快指针每次走 2 步，慢指针每次走 1 步
- 若有环，快指针最终会追上慢指针（相对速度 1，不会跳过）；若无环，快指针先到达 null
- 时间复杂度 O(n)，空间复杂度 O(1)

**题解代码（Python）**：
```python
class Solution:
    def hasCycle(self, head: Optional[ListNode]) -> bool:
        slow = fast = head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
            if slow is fast:
                return True
        return False
```

**题解代码（Java）**：
```java
public class Solution {
    public boolean hasCycle(ListNode head) {
        ListNode slow = head, fast = head;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
            if (slow == fast) return true;
        }
        return false;
    }
}
```

**题解代码（Go）**：
```go

        }
```

## 5. 环形链表 II（142）

**难度**：中等

**题目描述**：给定一个链表的头节点 `head`，返回链表开始入环的第一个节点。如果链表无环，则返回 `null`。不允许修改 链表。

**原题链接**：https://leetcode.cn/problems/linked-list-cycle-ii/

**解题思路**：
- 阶段一：快慢指针判环，相遇时慢指针走了 `a + b`（a 为头到入口距离，b 为入口到相遇点距离）
- 阶段二：由 `2(a+b) = a + b + n·环长` 推出 `a = n·环长 - b`，即从相遇点走 a 步正好回到入口
- 让一个指针从头、另一个从相遇点同速前进，再次相遇处即入口
- 时间复杂度 O(n)，空间复杂度 O(1)

**题解代码（Python）**：
```python
class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        slow = fast = head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
            if slow is fast:  # 有环，找入口
                p = head
                while p is not slow:
                    p = p.next
                    slow = slow.next
                return slow
        return None
```

**题解代码（Java）**：
```java

                while (p != slow) {
                    p = p.next;
                    slow = slow.next;
                }
                return slow;
            }
        }
        return null;
    }
}
```

**题解代码（Go）**：

## 6. 合并两个有序链表（21）

**难度**：简单

**题目描述**：将两个升序链表合并为一个新的 升序 链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

**原题链接**：https://leetcode.cn/problems/merge-two-sorted-lists/

**解题思路**：
- 哑结点 + 逐一比较：取两链表中较小的节点接到结果尾部，指针后移
- 某一链表为空时，直接把另一链表剩余部分接到尾部
- 也可写成递归：`merge(l1, l2) = 较小者 + merge(其余)`
- 时间复杂度 O(m + n)，空间迭代 O(1)

**题解代码（Python）**：
```python
class Solution:
    def mergeTwoLists(self, list1: Optional[ListNode], list2: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode(0)
        cur = dummy
        while list1 and list2:
            if list1.val <= list2.val:
                cur.next, list1 = list1, list1.next
            else:
                cur.next, list2 = list2, list2.next
            cur = cur.next
        cur.next = list1 if list1 else list2
        return dummy.next
```

**题解代码（Java）**：
```java
class Solution {
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        ListNode dummy = new ListNode(0), cur = dummy;
        while (list1 != null && list2 != null) {
            if (list1.val <= list2.val) {
                cur.next = list1;
                list1 = list1.next;
            } else {
                cur.next = list2;
                list2 = list2.next;
            }
            cur = cur.next;
        }
        cur.next = (list1 != null) ? list1 : list2;
        return dummy.next;
    }
}
```

**题解代码（Go）**：
```go

        }
        cur = cur.Next
    }

        cur.Next = list1
    } else {
        cur.Next = list2
    }
    return dummy.Next
}
```

## 7. 两数相加（2）

**难度**：中等

**题目描述**：给你两个 非空 的链表，表示两个非负的整数。它们每位数字都是按照 逆序 的方式存储的，并且每个节点只能存储 一位 数字。请你将两个数相加，并以相同形式返回一个表示和的链表。

**原题链接**：https://leetcode.cn/problems/add-two-numbers/

**解题思路**：
- 模拟竖式加法：同时遍历两链表，逐位相加并处理进位 carry
- 链表是逆序存储，最低位在前，天然适合从低位开始加
- 两链表长度不一时短的按 0 处理；结束后若有进位需补一个节点
- 时间复杂度 O(max(m, n))，空间 O(1)（不计输出）

**题解代码（Python）**：
```python
class Solution:
    def addTwoNumbers(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode(0)
        cur, carry = dummy, 0
        while l1 or l2 or carry:
            s = carry
            if l1:
                s += l1.val
                l1 = l1.next
            if l2:
                s += l2.val
                l2 = l2.next
            carry, digit = divmod(s, 10)
            cur.next = ListNode(digit)
            cur = cur.next
        return dummy.next
```

**题解代码（Java）**：
```java

        }
        return dummy.next;
    }
}
```

## 8. 删除链表的倒数第 N 个结点（19）

**难度**：中等

**题目描述**：给你一个链表，删除链表的倒数第 `n` 个结点，并且返回链表的头结点。进阶：你能尝试使用一趟扫描实现吗？

**原题链接**：https://leetcode.cn/problems/remove-nth-node-from-end-of-list/

**解题思路**：
- 双指针一次遍历：快指针先走 n+1 步，然后快慢同速前进
- 快指针到 null 时，慢指针停在倒数第 n+1 个节点，直接跳过倒数第 n 个
- 哑结点统一处理删除头节点的情况
- 时间复杂度 O(L)，空间复杂度 O(1)

**题解代码（Python）**：
```python
class Solution:
    def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
        dummy = ListNode(0, head)
        fast = slow = dummy
        for _ in range(n + 1):
            fast = fast.next
        while fast:
            fast = fast.next
            slow = slow.next
        slow.next = slow.next.next
        return dummy.next
```

**题解代码（Java）**：
```java

        while (fast != null) {
            fast = fast.next;

        slow.next = slow.next.next;
        return dummy.next;
    }
}
```

**题解代码（Go）**：

## 9. 两两交换链表中的节点（24）

**难度**：中等

**题目描述**：给你一个链表，两两交换其中相邻的节点，并返回交换后链表的头节点。你必须在不修改节点内部的值的情况下完成本题（即，只能进行节点交换）。

**原题链接**：https://leetcode.cn/problems/swap-nodes-in-pairs/

**解题思路**：
- 哑结点 + 迭代：每次处理一对（node0 → node1 → node2）
- 交换操作：`node0.next = node2; node1.next = node2.next; node2.next = node1`，然后 node0 移动到 node1
- 也可递归：`swap(head) = 交换 head 和 head.next 后，head.next.next = swap(其余)`
- 时间复杂度 O(n)，空间迭代 O(1)

**题解代码（Python）**：
```python
class Solution:
    def swapPairs(self, head: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode(0, head)
        node0 = dummy
        while node0.next and node0.next.next:
            node1, node2 = node0.next, node0.next.next
            node0.next = node2
            node1.next = node2.next
            node2.next = node1
            node0 = node1
        return dummy.next
```

**题解代码（Java）**：
```java

    }
}
```

## 10. K 个一组翻转链表（25）

**难度**：困难

**题目描述**：给你链表的头节点 `head`，每 `k` 个节点一组进行翻转，请你返回修改后的链表。如果节点总数不是 `k` 的整数倍，那么请将最后剩余的节点保持原有顺序。你不能只是单纯的改变节点内部的值，而是需要实际进行节点交换。

**原题链接**：https://leetcode.cn/problems/reverse-nodes-in-k-group/

**解题思路**：
- 哑结点 + 分组处理：prev 指向每组的前驱，先探查这组是否有 k 个节点（end 移动 k 步）
- 有则断开该组，组内反转（复用反转链表逻辑），再接回前驱和后继；prev 移到这组反转后的尾节点
- 不足 k 个则直接结束
- 时间复杂度 O(n)，空间复杂度 O(1)

**题解代码（Python）**：
```python
class Solution:
    def reverseKGroup(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
        dummy = ListNode(0, head)
        prev = dummy
        while True:
            end = prev
            for _ in range(k):
                end = end.next
                if not end:
                    return dummy.next
            nxt = end.next
            start = prev.next
            end.next = None
            prev.next = self.reverse(start)
            start.next = nxt
            prev = start

    def reverse(self, head):
        prev, cur = None, head
        while cur:
            cur.next, prev, cur = prev, cur, cur.next
        return prev
```

**题解代码（Java）**：
```java

    public ListNode reverseKGroup(ListNode head, int k) {
        ListNode dummy = new ListNode(0, head), prev = dummy;
        while (true) {
            ListNode end = prev;
            for (int i = 0; i < k; i++) {
                end = end.next;
                if (end == null) return dummy.next;
            }
            ListNode nxt = end.next;
            ListNode start = prev.next;
            end.next = null;
            prev.next = reverse(start);
            start.next = nxt;
            prev = start;
        }
    }

    private ListNode reverse(ListNode head) {
        ListNode prev = null, cur = head;
        while (cur != null) {
            ListNode nxt = cur.next;
            cur.next = prev;
            prev = cur;
            cur = nxt;
        }
        return prev;
    }
}
```

```go
        cur.Next, prev, cur = prev, cur, cur.Next
    }
    return prev
```

## 11. 随机链表的复制（138）

**难度**：中等

**题目描述**：给你一个长度为 `n` 的链表，每个节点包含一个额外增加的随机指针 `random`，该指针可以指向链表中的任何节点或空节点。构造这个链表的 深拷贝，并返回复制链表的头节点。

**原题链接**：https://leetcode.cn/problems/copy-list-with-random-pointer/

**解题思路**：
- 方法一（哈希表）：第一遍遍历建立 `原节点 → 新节点` 映射，第二遍为每个新节点设置 next 和 random
- 方法二（原地拼接）：每个新节点插到原节点后面，`cur.random.next` 即为拷贝的 random，最后拆分两条链
- 时间复杂度 O(n)，哈希法空间 O(n)，拼接法空间 O(1)

**题解代码（Python）**：
```python
class Solution:
    def copyRandomList(self, head: 'Optional[Node]') -> 'Optional[Node]':
        if not head:
            return None
        # 1. 复制节点插到原节点后面
        cur = head
        while cur:
            cur.next = Node(cur.val, cur.next)
            cur = cur.next.next
        # 2. 设置拷贝节点的 random
        cur = head
        while cur:
            if cur.random:
                cur.next.random = cur.random.next
            cur = cur.next.next
        # 3. 拆分两条链表
        dummy = head.next
        cur = head
        while cur.next:
            copy = cur.next
            cur.next = copy.next
            if copy.next:
                copy.next = copy.next.next
            cur = cur.next
        return dummy
```

## 12. 排序链表（148）

**难度**：中等

**题目描述**：给你链表的头结点 `head`，请将其按 升序 排列并返回 排序后的链表。进阶：你可以在 O(n log n) 时间复杂度和常数级空间复杂度下，对链表进行排序吗？

**原题链接**：https://leetcode.cn/problems/sort-list/

**解题思路**：
- 归并排序：快慢指针找中点断开 → 递归排序两半 → 合并两个有序链表
- 达到 O(n log n) 时间；递归栈为 O(log n)，若要求严格 O(1) 空间需自底向上归并（迭代按长度 1, 2, 4... 分组合并）
- 快指针走两步慢指针走一步，断链前先把 slow.next 置 null

**题解代码（Python）**：
```python
class Solution:
    def sortList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if not head or not head.next:
            return head
        # 快慢指针找中点
        slow, fast = head, head.next
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
        mid = slow.next
        slow.next = None
        # 递归排序两半后合并
        return self.merge(self.sortList(head), self.sortList(mid))

    def merge(self, l1, l2):
        dummy = cur = ListNode(0)
        while l1 and l2:
            if l1.val <= l2.val:
                cur.next, l1 = l1, l1.next
            else:
                cur.next, l2 = l2, l2.next
            cur = cur.next
        cur.next = l1 if l1 else l2
        return dummy.next
```

## 13. 合并 K 个升序链表（23）

**难度**：困难

**题目描述**：给你一个链表数组，每个链表都已经按升序排列。请你将所有链表合并到一个升序链表中，返回合并后的链表。

**原题链接**：https://leetcode.cn/problems/merge-k-sorted-lists/

**解题思路**：
- 方法一（最小堆）：把 k 个链表头放入小顶堆，每次弹出最小的接到结果尾部，并把它的 next 入堆。时间 O(N log k)，N 为总节点数
- 方法二（分治）：两两合并（复用合并两个有序链表），每轮链表数减半，log k 轮
- 时间复杂度 O(N log k)，空间堆法 O(k)

**题解代码（Python）**：
```python
class Solution:
    def mergeKLists(self, lists: List[Optional[ListNode]]) -> Optional[ListNode]:
        heap = []
        for i, node in enumerate(lists):
            if node:
                heapq.heappush(heap, (node.val, i, node))
        dummy = cur = ListNode(0)
        while heap:
            val, i, node = heapq.heappop(heap)
            cur.next = node
            cur = cur.next
            if node.next:
                heapq.heappush(heap, (node.next.val, i, node.next))
        return dummy.next
```

**题解代码（Java）**：
```java
class Solution {
    public ListNode mergeKLists(ListNode[] lists) {
        PriorityQueue<ListNode> pq = new PriorityQueue<>((a, b) -> a.val - b.val);
        for (ListNode node : lists) {
            if (node != null) pq.offer(node);
        }
        ListNode dummy = new ListNode(0), cur = dummy;
        while (!pq.isEmpty()) {
            ListNode node = pq.poll();
            cur.next = node;
            cur = cur.next;
            if (node.next != null) pq.offer(node.next);
        }
        return dummy.next;
    }
}
```

## 14. LRU 缓存（146）

**难度**：中等

**题目描述**：请你设计并实现一个满足 LRU (最近最少使用) 缓存 约束的数据结构。实现 `LRUCache` 类：`LRUCache(int capacity)` 初始化；`int get(int key)` 存在则返回值否则返回 -1；`void put(int key, int value)` 不存在则插入，存在则更新。如果插入导致键数超过容量，应当 逐出 最久未使用的键。`get` 和 `put` 均需以 O(1) 的平均时间复杂度运行。

**原题链接**：https://leetcode.cn/problems/lru-cache/

**解题思路**：
- 哈希表 + 双向链表：哈希表 O(1) 定位节点，双向链表 O(1) 移动/删除节点
- 链表头部表示最近使用，尾部表示最久未使用
- get/put 都要把节点移到头部；put 超容量时删除尾部节点并同步删哈希表
- 用哑头、哑尾简化边界处理
- 时间复杂度 O(1)，空间复杂度 O(capacity)

**题解代码（Python）**：
```python
class Node:
    def __init__(self, key=0, value=0):
        self.key, self.value = key, value
        self.prev = self.next = None

class LRUCache:
    def __init__(self, capacity: int):
        self.cap = capacity
        self.map = {}
        self.head, self.tail = Node(), Node()  # 哑头哑尾
        self.head.next, self.tail.prev = self.tail, self.head

    def _remove(self, node):
        node.prev.next, node.next.prev = node.next, node.prev

    def _add_first(self, node):
        node.next, node.prev = self.head.next, self.head
        self.head.next.prev, self.head.next = node, node

    def get(self, key: int) -> int:
        if key not in self.map:
            return -1
        node = self.map[key]
        self._remove(node)
        self._add_first(node)
        return node.value

    def put(self, key: int, value: int) -> None:
        if key in self.map:
            node = self.map[key]
            node.value = value
            self._remove(node)
            self._add_first(node)
        else:
            if len(self.map) >= self.cap:
                last = self.tail.prev
                self._remove(last)
                del self.map[last.key]
            node = Node(key, value)
            self.map[key] = node
            self._add_first(node)
```

**题解代码（Java）**：
```java
class LRUCache {
    class Node {
        int key, value;
        Node prev, next;
        Node(int key, int value) { this.key = key; this.value = value; }
    }

    private final int cap;
    private final Map<Integer, Node> map = new HashMap<>();
    private final Node head = new Node(0, 0), tail = new Node(0, 0);

    public LRUCache(int capacity) {
        cap = capacity;
        head.next = tail;
        tail.prev = head;
    }

    private void remove(Node node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }

    private void addFirst(Node node) {
        node.next = head.next;
        node.prev = head;
        head.next.prev = node;
        head.next = node;
    }

    public int get(int key) {
        Node node = map.get(key);
        if (node == null) return -1;
        remove(node);
        addFirst(node);
        return node.value;
    }

    public void put(int key, int value) {
        Node node = map.get(key);
        if (node != null) {
            node.value = value;
            remove(node);
            addFirst(node);
        } else {
            if (map.size() >= cap) {
                Node last = tail.prev;
                remove(last);
                map.remove(last.key);
            }
            node = new Node(key, value);
            map.put(key, node);
            addFirst(node);
        }
    }
}
```
