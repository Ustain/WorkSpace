# 贪心算法（4题）

## 1. 买卖股票的最佳时机（121）

**难度**：简单

**题目描述**：给定一个数组 `prices`，它的第 `i` 个元素 `prices[i]` 表示一支给定股票第 `i` 天的价格。你只能选择 某一天 买入这只股票，并选择在 未来的某一个不同的日子 卖出该股票。设计一个算法来计算你所能获取的最大利润。如果你不能获取任何利润，返回 0。

**原题链接**：https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/

**解题思路**：
- 一次遍历：维护到当前天为止的最低买入价 minPrice
- 每天尝试卖出：`max(当前利润, prices[i] - minPrice)`；同时更新 minPrice
- 时间复杂度 O(n)，空间 O(1)

**题解代码（Python）**：
```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        min_price, ans = float('inf'), 0
        for price in prices:
            ans = max(ans, price - min_price)
            min_price = min(min_price, price)
        return ans
```

**题解代码（Java）**：
```java
class Solution {
    public int maxProfit(int[] prices) {
        int minPrice = Integer.MAX_VALUE, ans = 0;
        for (int price : prices) {
            ans = Math.max(ans, price - minPrice);
            minPrice = Math.min(minPrice, price);
        }
        return ans;
    }
}
```

**题解代码（Go）**：
```go
func maxProfit(prices []int) int {
    minPrice, ans := math.MaxInt64, 0
    for _, price := range prices {
        if profit := price - minPrice; profit > ans {
            ans = profit
        }
        if price < minPrice {
            minPrice = price
        }
    }
    return ans
}
```

## 2. 跳跃游戏（55）

**难度**：中等

**题目描述**：给你一个非负整数数组 `nums`，你最初位于数组的 第一个下标。数组中的每个元素代表你在该位置可以跳跃的最大长度。判断你是否能够到达最后一个下标，如果可以，返回 `true`；否则，返回 `false`。

**原题链接**：https://leetcode.cn/problems/jump-game/

**解题思路**：
- 贪心维护"最远可达位置" farthest：遍历到 i 时若 `i > farthest` 说明卡死，返回 false
- 否则更新 `farthest = max(farthest, i + nums[i])`，farthest ≥ n-1 即可达
- 时间复杂度 O(n)，空间 O(1)

**题解代码（Python）**：
```python
class Solution:
    def canJump(self, nums: List[int]) -> bool:
        farthest = 0
        for i, jump in enumerate(nums):
            if i > farthest:
                return False
            farthest = max(farthest, i + jump)
            if farthest >= len(nums) - 1:
                return True
        return True
```

**题解代码（Java）**：
```java
class Solution {
    public boolean canJump(int[] nums) {
        int farthest = 0;
        for (int i = 0; i < nums.length; i++) {
            if (i > farthest) return false;
            farthest = Math.max(farthest, i + nums[i]);
            if (farthest >= nums.length - 1) return true;
        }
        return true;
    }
}
```

**题解代码（Go）**：
```go
func canJump(nums []int) bool {
    farthest := 0
    for i, jump := range nums {
        if i > farthest {
            return false
        }
        if i+jump > farthest {
            farthest = i + jump
        }
        if farthest >= len(nums)-1 {
            return true
        }
    }
    return true
}
```

## 3. 跳跃游戏 II（45）

**难度**：中等

**题目描述**：给定一个长度为 `n` 的 0 索引整数数组 `nums`。初始位置为 `nums[0]`。每个元素 `nums[i]` 表示从索引 `i` 向前跳转的最大长度。即如果你在 `nums[i]` 处，你可以跳转到任意 `nums[i + j]` 处（`0 <= j <= nums[i]` 且 `i + j < n`）。返回到达 `nums[n - 1]` 的最小跳跃次数。生成的测试用例可以到达 `nums[n - 1]`。

**原题链接**：https://leetcode.cn/problems/jump-game-ii/

**解题思路**：
- 贪心按"层"跳：维护当前跳跃边界 end 与下一层最远位置 farthest
- 遍历到 i == end 时说明本层用完，步数 +1，end = farthest（隐式 BFS 层序）
- 时间复杂度 O(n)，空间 O(1)

**题解代码（Python）**：
```python
class Solution:
    def jump(self, nums: List[int]) -> int:
        steps = end = farthest = 0
        for i in range(len(nums) - 1):  # 不访问最后一格
            farthest = max(farthest, i + nums[i])
            if i == end:
                steps += 1
                end = farthest
        return steps
```

**题解代码（Java）**：
```java
class Solution {
    public int jump(int[] nums) {
        int steps = 0, end = 0, farthest = 0;
        for (int i = 0; i < nums.length - 1; i++) {
            farthest = Math.max(farthest, i + nums[i]);
            if (i == end) {
                steps++;
                end = farthest;
            }
        }
        return steps;
    }
}
```

**题解代码（Go）**：
```go
func jump(nums []int) int {
    steps, end, farthest := 0, 0, 0
    for i := 0; i < len(nums)-1; i++ { // 不访问最后一格
        if i+nums[i] > farthest {
            farthest = i + nums[i]
        }
        if i == end {
            steps++
            end = farthest
        }
    }
    return steps
}
```

## 4. 划分字母区间（763）

**难度**：中等

**题目描述**：给你一个字符串 `s`。我们要把这个字符串划分为尽可能多的片段，同一字母最多出现在一个片段中。注意，划分结果需要满足：将所有划分结果按顺序连接，得到的字符串仍然是 `s`。返回一个表示每个字符串片段的长度的列表。

**原题链接**：https://leetcode.cn/problems/partition-labels/

**解题思路**：
- 先记录每个字母最后一次出现的下标 last[c]
- 贪心扩展：遍历时维护当前片段的结束边界 end = max(end, last[s[i]])；当 i == end 时片段闭合，记录长度
- 时间复杂度 O(n)，空间 O(|Σ|)

**题解代码（Python）**：
```python
class Solution:
    def partitionLabels(self, s: str) -> List[int]:
        last = {ch: i for i, ch in enumerate(s)}
        ans = []
        start = end = 0
        for i, ch in enumerate(s):
            end = max(end, last[ch])
            if i == end:
                ans.append(end - start + 1)
                start = i + 1
        return ans
```

**题解代码（Java）**：
```java
class Solution {
    public List<Integer> partitionLabels(String s) {
        int[] last = new int[26];
        for (int i = 0; i < s.length(); i++) {
            last[s.charAt(i) - 'a'] = i;
        }
        List<Integer> ans = new ArrayList<>();
        int start = 0, end = 0;
        for (int i = 0; i < s.length(); i++) {
            end = Math.max(end, last[s.charAt(i) - 'a']);
            if (i == end) {
                ans.add(end - start + 1);
                start = i + 1;
            }
        }
        return ans;
    }
}
```

**题解代码（Go）**：
```go
func partitionLabels(s string) []int {
    last := map[byte]int{}
    for i := 0; i < len(s); i++ {
        last[s[i]] = i
    }
    ans := []int{}
    start, end := 0, 0
    for i := 0; i < len(s); i++ {
        if last[s[i]] > end {
            end = last[s[i]]
        }
        if i == end {
            ans = append(ans, end-start+1)
            start = i + 1
        }
    }
    return ans
}
```
