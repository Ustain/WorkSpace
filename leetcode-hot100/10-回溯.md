## 1. 全排列（46）

**难度**：中等

**题目描述**：给定一个不含重复数字的数组 `nums`，返回其 所有可能的全排列。你可以 按任意顺序 返回答案。

**原题链接**：https://leetcode.cn/problems/permutations/

**解题思路**：
- 回溯模板：用 path 记录当前排列，used 数组标记已用元素
- 每次从未使用的元素中选一个加入 path，递归到下一层，返回时撤销选择
- 长度达到 n 时收集答案
- 时间复杂度 O(n · n!)，空间 O(n)

**题解代码（Python）**：
```python
class Solution:
    def permute(self, nums: List[int]) -> List[List[int]]:
        n = len(nums)
        ans, path, used = [], [], [False] * n
        def backtrack():
            if len(path) == n:
                ans.append(path[:])
                return
            for i in range(n):
                if used[i]:
                    continue
                used[i] = True
                path.append(nums[i])
                backtrack()
                path.pop()
                used[i] = False
        backtrack()
        return ans
```

**题解代码（Java）**：
```java
class Solution {
    public List<List<Integer>> permute(int[] nums) {
        List<List<Integer>> ans = new ArrayList<>();
        backtrack(nums, new boolean[nums.length], new ArrayList<>(), ans);
        return ans;
    }

    private void backtrack(int[] nums, boolean[] used, List<Integer> path,
                           List<List<Integer>> ans) {
        if (path.size() == nums.length) {
            ans.add(new ArrayList<>(path));
            return;
        }
        for (int i = 0; i < nums.length; i++) {
            if (used[i]) continue;
            used[i] = true;
            path.add(nums[i]);
            backtrack(nums, used, path, ans);
            path.remove(path.size() - 1);
            used[i] = false;
        }
    }
}
```

**题解代码（Go）**：
```go
func permute(nums []int) [][]int {
    n := len(nums)
    ans := [][]int{}
    path := []int{}
    used := make([]bool, n)
    var backtrack func()
    backtrack = func() {
        if len(path) == n {
            ans = append(ans, append([]int{}, path...))
            return
        }
        for i := 0; i < n; i++ {
            if used[i] {
                continue
            }
            used[i] = true
            path = append(path, nums[i])
            backtrack()
            path = path[:len(path)-1]
            used[i] = false
        }
    }
    backtrack()
    return ans
}
```

## 2. 子集（78）

**难度**：中等

**题目描述**：给你一个整数数组 `nums`，数组中的元素 互不相同。返回该数组所有可能的子集（幂集）。解集 不能 包含重复的子集。你可以按 任意顺序 返回解集。

**原题链接**：https://leetcode.cn/problems/subsets/

**解题思路**：
- 每个元素选或不选，共 2ⁿ 个子集
- 回溯时按索引递增选元素：进入每层先把当前 path 收进答案（每个节点都是一个子集），再从 start 位置继续扩展
- 时间复杂度 O(n · 2ⁿ)，空间 O(n)

**题解代码（Python）**：
```python
class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        ans, path = [], []
        def backtrack(start):
            ans.append(path[:])  # 每个节点都是子集
            for i in range(start, len(nums)):
                path.append(nums[i])
                backtrack(i + 1)
                path.pop()
        backtrack(0)
        return ans
```

## 3. 组合总和（39）

**难度**：中等

**题目描述**：给你一个 无重复元素 的整数数组 `candidates` 和一个目标整数 `target`，找出 `candidates` 中可以使数字和为目标数 `target` 的 所有 不同组合，并以列表形式返回。你可以按任意顺序返回这些组合。candidates 中的 同一个 数字可以 无限制重复被选取。如果至少一个数字的被选数量不同，则两种组合是不同的。

**原题链接**：https://leetcode.cn/problems/combination-sum/

**解题思路**：
- 回溯 + 剪枝：从 start 索引开始（避免重复组合），元素可重复选取所以递归时传 `i` 而不是 `i + 1`
- 剩余值 remain 减到 0 收集答案；减到负数剪枝（可先排序，用 break 代替 continue 加速）
- 时间复杂度 O(2^target · k)，空间 O(target)

**题解代码（Python）**：
```python
class Solution:
    def combinationSum(self, candidates: List[int], target: int) -> List[List[int]]:
        candidates.sort()
        ans, path = [], []
        def backtrack(start, remain):
            if remain == 0:
                ans.append(path[:])
                return
            for i in range(start, len(candidates)):
                if candidates[i] > remain:
                    break  # 剪枝
                path.append(candidates[i])
                backtrack(i, remain - candidates[i])  # i 可重复选
                path.pop()
        backtrack(0, target)
        return ans
```

```java
        }
    }
```

## 4. 括号生成（22）

**难度**：中等

**题目描述**：数字 `n` 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且 有效的 括号组合。

**原题链接**：https://leetcode.cn/problems/generate-parentheses/

**解题思路**：
- 回溯：维护已用的左括号数 left、右括号数 right
- 约束：左括号可以放（left < n）；右括号只有在 right < left 时可放（保证有效）
- 长度达到 2n 时收集答案
- 时间复杂度约 O(4ⁿ / √n)（卡特兰数），空间 O(n)

**题解代码（Python）**：
```python
class Solution:
    def generateParenthesis(self, n: int) -> List[str]:
        ans, path = [], []
        def backtrack(left, right):
            if len(path) == 2 * n:
                ans.append(''.join(path))
                return
            if left < n:
                path.append('(')
                backtrack(left + 1, right)
                path.pop()
            if right < left:
                path.append(')')
                backtrack(left, right + 1)
                path.pop()
        backtrack(0, 0)
        return ans
```

**题解代码（Java）**：
```java

            path.deleteCharAt(path.length() - 1);
        }
        if (right < left) {
            path.append(')');
            backtrack(n, left, right + 1, path, ans);
            path.deleteCharAt(path.length() - 1);
        }
    }
}
```

## 5. 电话号码的字母组合（17）

**难度**：中等

**题目描述**：给定一个仅包含数字 `2-9` 的字符串，返回所有它能表示的字母组合。答案可以按 任意顺序 返回。给出数字到字母的映射如下（与电话按键相同）。注意 1 不对应任何字母。

**原题链接**：https://leetcode.cn/problems/letter-combinations-of-a-phone-number/

**解题思路**：
- 建立数字到字母串的映射表，回溯按 digits 的每一位依次选字母
- 第 i 层从映射表 `digits[i]` 对应的字母中选一个，递归 i+1 层
- digits 为空返回空列表
- 时间复杂度 O(3^m · 4^n)（m、n 为对应 3/4 字母键的个数），空间 O(n)

**题解代码（Python）**：
```python
class Solution:
    def letterCombinations(self, digits: str) -> List[str]:
        if not digits:
            return []
        mapping = ["", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"]
        ans, path = [], []
        def backtrack(index):
            if index == len(digits):
                ans.append(''.join(path))
                return
            for ch in mapping[int(digits[index])]:
                path.append(ch)
                backtrack(index + 1)
                path.pop()
        backtrack(0)
        return ans
```

**题解代码（Java）**：
```java
class Solution {
    private static final String[] MAPPING = {"", "", "abc", "def", "ghi",
            "jkl", "mno", "pqrs", "tuv", "wxyz"};

    public List<String> letterCombinations(String digits) {
        List<String> ans = new ArrayList<>();
        if (digits.isEmpty()) return ans;
        backtrack(digits, 0, new StringBuilder(), ans);
        return ans;
    }

    private void backtrack(String digits, int index, StringBuilder path,
                           List<String> ans) {
        if (index == digits.length()) {
            ans.add(path.toString());
            return;
        }
        for (char ch : MAPPING[digits.charAt(index) - '0'].toCharArray()) {
            path.append(ch);
            backtrack(digits, index + 1, path, ans);
            path.deleteCharAt(path.length() - 1);
        }
    }
}
```

## 6. 单词搜索（79）

**难度**：中等

**题目描述**：给定一个 `m x n` 二维字符网格 `board` 和一个字符串单词 `word`。如果 `word` 存在于网格中，返回 `true`；否则，返回 `false`。单词必须按照字母顺序，通过相邻的单元格内的字母构成，其中"相邻"单元格是那些水平相邻或垂直相邻的单元格。同一个单元格内的字母不允许被重复使用。

**原题链接**：https://leetcode.cn/problems/word-search/

**解题思路**：
- 从每个格子尝试 DFS：`dfs(i, j, k)` 判断从 (i, j) 出发能否匹配 word[k:]
- 不匹配立即返回 false；匹配到最后一个字符返回 true
- 走过的格子临时置为特殊字符标记已访问，四方向递归后恢复
- 时间复杂度 O(mn · 3^L)，空间 O(L)

**题解代码（Python）**：
```python
class Solution:
    def exist(self, board: List[List[str]], word: str) -> bool:
        m, n = len(board), len(board[0])

        def dfs(i, j, k):
            if board[i][j] != word[k]:
                return False
            if k == len(word) - 1:
                return True
            board[i][j] = '#'  # 标记已访问
            found = False
            for di, dj in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                ni, nj = i + di, j + dj
                if 0 <= ni < m and 0 <= nj < n and dfs(ni, nj, k + 1):
                    found = True
                    break
            board[i][j] = word[k]  # 恢复
            return found

        return any(dfs(i, j, 0) for i in range(m) for j in range(n))
```

**题解代码（Java）**：
```java
class Solution {
    public boolean exist(char[][] board, String word) {
        int m = board.length, n = board[0].length;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (dfs(board, word, i, j, 0)) return true;
            }
        }
        return false;
    }

    private boolean dfs(char[][] board, String word, int i, int j, int k) {
        if (board[i][j] != word.charAt(k)) return false;
        if (k == word.length() - 1) return true;
        board[i][j] = '#';
        boolean found = false;
        int[][] dirs = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
        for (int[] d : dirs) {
            int ni = i + d[0], nj = j + d[1];
            if (ni >= 0 && ni < board.length && nj >= 0 && nj < board[0].length
                    && dfs(board, word, ni, nj, k + 1)) {
                found = true;
                break;
            }
        }
        board[i][j] = word.charAt(k);
        return found;
    }
}
```

## 7. 分割回文串（131）

**难度**：中等

**题目描述**：给你一个字符串 `s`，请你将 `s` 分割成一些子串，使每个子串都是 回文串。返回 `s` 所有可能的分割方案。

**原题链接**：https://leetcode.cn/problems/palindrome-partitioning/

**解题思路**：
- 回溯：从 start 出发，枚举所有前缀 `s[start:i+1]`，是回文则加入 path 并递归 i+1
- start 到达末尾时收集答案
- 预计算 `isPal[i][j]`（动态规划：`s[i]==s[j]` 且 `isPal[i+1][j-1]`）可把判断降到 O(1)
- 时间复杂度 O(n · 2ⁿ)，空间 O(n²)

**题解代码（Python）**：
```python
class Solution:
    def partition(self, s: str) -> List[List[str]]:
        n = len(s)
        # isPal[i][j]: s[i..j] 是否为回文
        isPal = [[True] * n for _ in range(n)]
        for i in range(n - 1, -1, -1):
            for j in range(i + 1, n):
                isPal[i][j] = (s[i] == s[j]) and isPal[i + 1][j - 1]
        ans, path = [], []
        def backtrack(start):
            if start == n:
                ans.append(path[:])
                return
            for end in range(start, n):
                if isPal[start][end]:
                    path.append(s[start:end + 1])
                    backtrack(end + 1)
                    path.pop()
        backtrack(0)
        return ans
```

**题解代码（Java）**：
```java

    public List<List<String>> partition(String s) {
        int n = s.length();
        boolean[][] isPal = new boolean[n][n];
        for (boolean[] row : isPal) Arrays.fill(row, true);
        for (int i = n - 1; i >= 0; i--) {
            for (int j = i + 1; j < n; j++) {
                isPal[i][j] = (s.charAt(i) == s.charAt(j)) && isPal[i + 1][j - 1];
            }
        }
        List<List<String>> ans = new ArrayList<>();
        backtrack(s, 0, isPal, new ArrayList<>(), ans);
        return ans;
    }

    private void backtrack(String s, int start, boolean[][] isPal,
                           List<String> path, List<List<String>> ans) {
        if (start == s.length()) {
            ans.add(new ArrayList<>(path));
            return;
        }
        for (int end = start; end < s.length(); end++) {
            if (isPal[start][end]) {
                path.add(s.substring(start, end + 1));
                backtrack(s, end + 1, isPal, path, ans);
                path.remove(path.size() - 1);
            }
        }
    }
}
```

## 8. N 皇后（51）

**难度**：困难

**题目描述**：按照国际象棋的规则，皇后可以攻击与之处在同一行或同一列或同一斜线上的棋子。n 皇后问题 研究的是如何将 `n` 个皇后放置在 `n × n` 的棋盘上，并且使皇后彼此之间不能相互攻击。给你一个整数 `n`，返回所有不同的 `n` 皇后问题的解决方案。每一种解法包含一个不同的 `n` 皇后问题 的棋子放置方案，该方案中 `'Q'` 和 `'.'` 分别代表了皇后和空位。

**原题链接**：https://leetcode.cn/problems/n-queens/

**解题思路**：
- 逐行放置：每行放一个皇后，只需检查列、主对角线（row - col）、副对角线（row + col）是否被占用
- 用三个集合记录被占用的列/对角线，回溯时撤销
- 同一主对角线 row-col 恒定，同一副对角线 row+col 恒定
- 找到一组合法放置时按行拼成字符串输出
- 时间复杂度 O(n!)，空间 O(n)

**题解代码（Python）**：
```python
class Solution:
    def solveNQueens(self, n: int) -> List[List[str]]:
        cols, diag1, diag2 = set(), set(), set()
        queens, ans = [], []  # queens[i] 表示第 i 行皇后所在列
        def backtrack(row):
            if row == n:
                ans.append(['.' * c + 'Q' + '.' * (n - c - 1) for c in queens])
                return
            for col in range(n):
                if col in cols or (row - col) in diag1 or (row + col) in diag2:
                    continue
                cols.add(col); diag1.add(row - col); diag2.add(row + col)
                queens.append(col)
                backtrack(row + 1)
                queens.pop()
                cols.remove(col); diag1.remove(row - col); diag2.remove(row + col)
        backtrack(0)
        return ans
```

**题解代码（Java）**：
```java
class Solution {
    public List<List<String>> solveNQueens(int n) {
        boolean[] cols = new boolean[n];
        boolean[] diag1 = new boolean[2 * n];
        boolean[] diag2 = new boolean[2 * n];
        int[] queens = new int[n];
        List<List<String>> ans = new ArrayList<>();
        backtrack(0, n, cols, diag1, diag2, queens, ans);
        return ans;
    }

    private void backtrack(int row, int n, boolean[] cols, boolean[] diag1,
                           boolean[] diag2, int[] queens, List<List<String>> ans) {
        if (row == n) {
            List<String> board = new ArrayList<>();
            for (int c : queens) {
                StringBuilder sb = new StringBuilder();
                for (int j = 0; j < n; j++) sb.append(j == c ? 'Q' : '.');
                board.add(sb.toString());
            }
            ans.add(board);
            return;
        }
        for (int col = 0; col < n; col++) {
            if (cols[col] || diag1[row - col + n] || diag2[row + col]) continue;
            cols[col] = diag1[row - col + n] = diag2[row + col] = true;
            queens[row] = col;
            backtrack(row + 1, n, cols, diag1, diag2, queens, ans);
            cols[col] = diag1[row - col + n] = diag2[row + col] = false;
        }
    }
}
```

```go
func solveNQueens(n int) [][]string {
    cols := make([]bool, n)
    diag1 := make([]bool, 2*n) // row - col + n
    diag2 := make([]bool, 2*n) // row + col
    queens := make([]int, n)
    ans := [][]string{}
    var backtrack func(row int)
    backtrack = func(row int) {
        if row == n {
            board := make([]string, n)
            for i, c := range queens {
                rowBytes := bytes.Repeat([]byte("."), n)
                rowBytes[c] = 'Q'
                board[i] = string(rowBytes)
            }
            ans = append(ans, board)
            return
        }
        for col := 0; col < n; col++ {
            if cols[col] || diag1[row-col+n] || diag2[row+col] {
                continue
            }
            cols[col], diag1[row-col+n], diag2[row+col] = true, true, true
            queens[row] = col
            backtrack(row + 1)
            cols[col], diag1[row-col+n], diag2[row+col] = false, false, false
        }
    }
    backtrack(0)
    return ans
}
```
