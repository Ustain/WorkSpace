# 普通数组（5题）

## 1. 最大子数组和（53）

**难度**：中等

**题目描述**：给你一个整数数组 `nums`，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

**原题链接**：https://leetcode.cn/problems/maximum-subarray/

**解题思路**：
- 动态规划（Kadane 算法）：`f(i)` 表示以第 i 个数结尾的最大子数组和
- 转移方程：`f(i) = max(f(i-1) + nums[i], nums[i])`——要么接在前一段后面，要么从自己重新开始
- 由于只依赖前一个状态，可用一个变量滚动，空间 O(1)
- 时间复杂度 O(n)


**题解代码（Go）**：
```go
func maxSubArray(nums []int) int {
    ans, pre := nums[0], nums[0]
    for _, num := range nums[1:] {
        if pre+num > num {
            pre += num
        } else {
            pre = num
        }
        if pre > ans {
            ans = pre
        }
    }
    return ans
}
```

## 2. 合并区间（56）

**难度**：中等

**题目描述**：以数组 `intervals` 表示若干个区间的集合，其中单个区间为 `intervals[i] = [starti, endi]`。请你合并所有重叠的区间，并返回 一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间。

**原题链接**：https://leetcode.cn/problems/merge-intervals/

**解题思路**：
- 按区间左端点排序，这样重叠区间必然相邻
- 遍历区间：若当前区间左端点 ≤ 结果集中最后一个区间的右端点，则合并（右端点取两者较大值）；否则作为新区间加入
- 时间复杂度 O(n log n)（排序），空间复杂度 O(log n)

**题解代码（Go）**：
```go
func merge(intervals [][]int) [][]int {
    sort.Slice(intervals, func(i, j int) bool { return intervals[i][0] < intervals[j][0] })
    merged := [][]int{}
    for _, interval := range intervals {
        if len(merged) == 0 || merged[len(merged)-1][1] < interval[0] { //如果当前左端点 > 结果集最后一组的右端点则说明无重叠，注意：相等属于重叠
            merged = append(merged, interval)
        } else if interval[1] > merged[len(merged)-1][1] {//需要当前右端点 > 结果集最后一组的右端点，说明不是外包的
            merged[len(merged)-1][1] = interval[1]
        }
        //外包的什么都不做
    }
    return merged
}
```

## 3. 轮转数组（189）

**难度**：中等

**题目描述**：给定一个整数数组 `nums`，将数组中的元素向右轮转 `k` 个位置，其中 `k` 是非负数。要求使用空间复杂度为 O(1) 的 原地 算法。

**原题链接**：https://leetcode.cn/problems/rotate-array/

**解题思路**：
- 环状替换或三次翻转法。三次翻转最直观：先整体翻转，再翻转前 k 个，再翻转后 n-k 个
- 例如 `[1,2,3,4,5,6,7], k=3`：整体翻转 `[7,6,5,4,3,2,1]` → 翻转前3个 `[5,6,7,4,3,2,1]` → 翻转后4个 `[5,6,7,1,2,3,4]`
- 注意 `k %= n` 防止越界
- 时间复杂度 O(n)，空间复杂度 O(1)

**题解代码（Go）**：
```go
func rotate(nums []int, k int) {
    n := len(nums)
    k %= n
    reverse := func(l, r int) {
        for l < r {
            nums[l], nums[r] = nums[r], nums[l]
            l++
            r--
        }
    }
    reverse(0, n-1)
    reverse(0, k-1)
    reverse(k, n-1)
}
```

## 4. 除自身以外数组的乘积（238）

**难度**：中等

**题目描述**：给你一个整数数组 `nums`，返回 数组 `answer`，其中 `answer[i]` 等于 `nums` 中除 `nums[i]` 之外其余各元素的乘积。题目数据保证数组之中任意元素的全部前缀元素和后缀的乘积都在 32 位 整数范围内。请 不要使用除法，且在 O(n) 时间复杂度内完成此题。

**原题链接**：https://leetcode.cn/problems/product-of-array-except-self/

**解题思路**：
- `answer[i] = 左边所有数的乘积 × 右边所有数的乘积`
- 先从左到右填充前缀乘积，再从右到左用一个变量 R 累积后缀乘积，边乘边更新 answer
- 时间复杂度 O(n)，除输出数组外空间 O(1)

**题解代码（Python）**：
```python
class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        n = len(nums)
        answer = [1] * n
        for i in range(1, n):  # answer[i] 先存左侧乘积
            answer[i] = answer[i - 1] * nums[i - 1]
        R = 1
        for i in range(n - 1, -1, -1):
            answer[i] *= R  # 再乘上右侧乘积
            R *= nums[i]
        return answer
```

**题解代码（Java）**：
```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] answer = new int[n];
        answer[0] = 1;
        for (int i = 1; i < n; i++) {
            answer[i] = answer[i - 1] * nums[i - 1];
        }
        int R = 1;
        for (int i = n - 1; i >= 0; i--) {
            answer[i] *= R;
            R *= nums[i];
        }
        return answer;
    }
}
```

    }

## 5. 缺失的第一个正数（41）

**难度**：困难

**题目描述**：给你一个未排序的整数数组 `nums`，请你找出其中没有出现的最小的正整数。请你实现时间复杂度为 O(n) 并且只使用常数级别额外空间的解决方案。

**原题链接**：https://leetcode.cn/problems/first-missing-positive/

**解题思路**：
- 答案一定在 `[1, n+1]` 之间（n 为数组长度）
- 原地哈希：把值 x（1 ≤ x ≤ n）换到下标 x-1 处，即 `nums[i] == i + 1`
- 遍历数组，若 `nums[i]` 在 `[1, n]` 且不在正确位置，交换到正确位置（用 while 循环直到当前位置正确）
- 最后从左到右找第一个 `nums[i] != i + 1` 的位置，返回 i+1；都正确则返回 n+1
- 时间复杂度 O(n)（每个数最多被交换一次到正确位置），空间 O(1)

**题解代码（Python）**：
```python
class Solution:
    def firstMissingPositive(self, nums: List[int]) -> int:
        n = len(nums)
        for i in range(n):
            # 把 nums[i] 换到它应在的位置 nums[i]-1
            while 1 <= nums[i] <= n and nums[nums[i] - 1] != nums[i]:
                nums[nums[i] - 1], nums[i] = nums[i], nums[nums[i] - 1]
        for i in range(n):
            if nums[i] != i + 1:
                return i + 1
        return n + 1
```

**题解代码（Java）**：
```java
class Solution {
    public int firstMissingPositive(int[] nums) {
        int n = nums.length;
        for (int i = 0; i < n; i++) {
            while (nums[i] >= 1 && nums[i] <= n && nums[nums[i] - 1] != nums[i]) {
                int tmp = nums[nums[i] - 1];
                nums[nums[i] - 1] = nums[i];
                nums[i] = tmp;
            }
        }
        for (int i = 0; i < n; i++) {
            if (nums[i] != i + 1) return i + 1;
        }
        return n + 1;
    }
}
```
