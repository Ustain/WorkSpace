# 矩阵（4题）

## 1. 矩阵置零（73）

**难度**：中等

**题目描述**：给定一个 `m x n` 的矩阵，如果一个元素为 0，则将其所在行和列的所有元素都设为 0。请使用 原地 算法。

**原题链接**：https://leetcode.cn/problems/set-matrix-zeroes/

**解题思路**：
- 朴素解法需 O(m+n) 标记数组；原地解法用矩阵第一行、第一列本身作为标记
- 先记录第一行、第一列自身是否含 0（两个布尔变量）
- 再遍历 `[1..m-1] × [1..n-1]`，元素为 0 时在对应的第一行/列做标记
- 根据标记把内部行列置零，最后处理第一行、第一列
- 时间复杂度 O(mn)，空间复杂度 O(1)

**题解代码（Python）**：
```python
class Solution:
    def setZeroes(self, matrix: List[List[int]]) -> None:
        m, n = len(matrix), len(matrix[0])
        first_row = any(matrix[0][j] == 0 for j in range(n))
        first_col = any(matrix[i][0] == 0 for i in range(m))
        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][j] == 0:
                    matrix[i][0] = matrix[0][j] = 0
        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][0] == 0 or matrix[0][j] == 0:
                    matrix[i][j] = 0
        if first_row:
            for j in range(n):
                matrix[0][j] = 0
        if first_col:
            for i in range(m):
                matrix[i][0] = 0
```

**题解代码（Java）**：
```java
class Solution {
    public void setZeroes(int[][] matrix) {
        int m = matrix.length, n = matrix[0].length;
        boolean firstRow = false, firstCol = false;
        for (int j = 0; j < n; j++) if (matrix[0][j] == 0) firstRow = true;
        for (int i = 0; i < m; i++) if (matrix[i][0] == 0) firstCol = true;
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                if (matrix[i][j] == 0) {
                    matrix[i][0] = 0;
                    matrix[0][j] = 0;
                }
            }
        }
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                if (matrix[i][0] == 0 || matrix[0][j] == 0) matrix[i][j] = 0;
            }
        }
        if (firstRow) for (int j = 0; j < n; j++) matrix[0][j] = 0;
        if (firstCol) for (int i = 0; i < m; i++) matrix[i][0] = 0;
    }
}
```

## 2. 螺旋矩阵（54）

**难度**：中等

**题目描述**：给你一个 `m` 行 `n` 列的矩阵 `matrix`，请按照 顺时针螺旋顺序，返回矩阵中的所有元素。

**原题链接**：https://leetcode.cn/problems/spiral-matrix/

**解题思路**：
- 维护四个边界：top、bottom、left、right，按"左→右、上→下、右→左、下→上"四轮遍历，每轮后收缩对应边界
- 每层遍历前检查边界是否仍然有效（避免单行/单列时重复访问）
- 时间复杂度 O(mn)，空间复杂度 O(1)（不计输出）

**题解代码（Python）**：
```python
class Solution:
    def spiralOrder(self, matrix: List[List[int]]) -> List[int]:
        m, n = len(matrix), len(matrix[0])
        top, bottom, left, right = 0, m - 1, 0, n - 1
        ans = []
        while top <= bottom and left <= right:
            for j in range(left, right + 1):
                ans.append(matrix[top][j])
            for i in range(top + 1, bottom + 1):
                ans.append(matrix[i][right])
            if top < bottom and left < right:
                for j in range(right - 1, left - 1, -1):
                    ans.append(matrix[bottom][j])
                for i in range(bottom - 1, top, -1):
                    ans.append(matrix[i][left])
            top, bottom, left, right = top + 1, bottom - 1, left + 1, right - 1
        return ans
```

**题解代码（Java）**：
```java
class Solution {
    public List<Integer> spiralOrder(int[][] matrix) {
        int m = matrix.length, n = matrix[0].length;
        int top = 0, bottom = m - 1, left = 0, right = n - 1;
        List<Integer> ans = new ArrayList<>();
        while (top <= bottom && left <= right) {
            for (int j = left; j <= right; j++) ans.add(matrix[top][j]);
            for (int i = top + 1; i <= bottom; i++) ans.add(matrix[i][right]);
            if (top < bottom && left < right) {
                for (int j = right - 1; j >= left; j--) ans.add(matrix[bottom][j]);
                for (int i = bottom - 1; i > top; i--) ans.add(matrix[i][left]);
            }
            top++; bottom--; left++; right--;
        }
        return ans;
    }
}
```

**题解代码（Go）**：
```go

    ans := []int{}
    for top <= bottom && left <= right {
        for j := left; j <= right; j++ {
            ans = append(ans, matrix[top][j])
        }
        for i := top + 1; i <= bottom; i++ {
            ans = append(ans, matrix[i][right])
        }

            for j := right - 1; j >= left; j-- {
                ans = append(ans, matrix[bottom][j])
            }
            for i := bottom - 1; i > top; i-- {
                ans = append(ans, matrix[i][left])
            }
        }
        top++
        bottom--
        left++
        right--
    }
    return ans
}
```

## 3. 旋转图像（48）

**难度**：中等

**题目描述**：给定一个 `n × n` 的二维矩阵 `matrix` 表示一个图像。请你将图像顺时针旋转 90 度。你必须在 原地 旋转图像，这意味着你需要直接修改输入的二维矩阵。请不要 使用另一个矩阵来旋转图像。

**原题链接**：https://leetcode.cn/problems/rotate-image/

**解题思路**：
- 两步原地变换：① 沿主对角线转置（交换 `matrix[i][j]` 与 `matrix[j][i]`）；② 每行左右翻转
- 转置 + 水平镜像 = 顺时针旋转 90°
- 时间复杂度 O(n²)，空间复杂度 O(1)

**题解代码（Python）**：
```python
class Solution:
    def rotate(self, matrix: List[List[int]]) -> None:
        n = len(matrix)
        # 1. 沿主对角线转置
        for i in range(n):
            for j in range(i + 1, n):
                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
        # 2. 每行左右翻转
        for row in matrix:
            row.reverse()
```

**题解代码（Java）**：
```java
class Solution {
    public void rotate(int[][] matrix) {
        int n = matrix.length;
        // 1. 沿主对角线转置
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                int tmp = matrix[i][j];
                matrix[i][j] = matrix[j][i];
                matrix[j][i] = tmp;
            }
        }
        // 2. 每行左右翻转
        for (int[] row : matrix) {
            for (int l = 0, r = n - 1; l < r; l++, r--) {
                int tmp = row[l];
                row[l] = row[r];
                row[r] = tmp;
            }
        }
    }
}
```

**题解代码（Go）**：
```go
func rotate(matrix [][]int) {
    n := len(matrix)
    // 1. 沿主对角线转置
    for i := 0; i < n; i++ {
        for j := i + 1; j < n; j++ {
            matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
        }
    }
    // 2. 每行左右翻转
    for _, row := range matrix {
        for l, r := 0, n-1; l < r; l, r = l+1, r-1 {
            row[l], row[r] = row[r], row[l]
        }
    }
}
```

## 4. 搜索二维矩阵 II（240）

**难度**：中等

**题目描述**：编写一个高效的算法来搜索 `m x n` 矩阵 `matrix` 中的一个目标值 `target`。该矩阵具有以下特性：每行的元素从左到右升序排列；每列的元素从上到下升序排列。

**原题链接**：https://leetcode.cn/problems/search-a-2d-matrix-ii/

**解题思路**：
- 从右上角出发（或左下角），把它看作二叉搜索树的根：左边比它小、下边比它大
- `matrix[row][col] > target` 则 col--，`< target` 则 row++，相等返回 true，越界返回 false
- 每步排除一行或一列，时间复杂度 O(m + n)，空间 O(1)

**题解代码（Python）**：
```python
class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        row, col = 0, len(matrix[0]) - 1
        while row < len(matrix) and col >= 0:
            if matrix[row][col] == target:
                return True
            elif matrix[row][col] > target:
                col -= 1
            else:
                row += 1
        return False
```

**题解代码（Java）**：
```java
class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        int row = 0, col = matrix[0].length - 1;
        while (row < matrix.length && col >= 0) {
            if (matrix[row][col] == target) return true;
            else if (matrix[row][col] > target) col--;
            else row++;
        }
        return false;
    }
}
```

**题解代码（Go）**：
