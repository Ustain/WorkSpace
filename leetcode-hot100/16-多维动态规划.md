## 1. 不同路径（62）

**难度**：中等

**题目描述**：一个机器人位于一个 `m x n` 网格的左上角（起始点在下图中标记为 "Start" ）。机器人每次只能向下或者向右移动一步。机器人试图达到网格的右下角（在下图中标记为 "Finish" ）。问总共有多少条不同的路径？

**原题链接**：https://leetcode.cn/problems/unique-paths/

**解题思路**：
- `f(i, j) = f(i-1, j) + f(i, j-1)`：到达格子的路径数 = 上方 + 左方
- 首行首列均为 1；用一维滚动数组优化：`f[j] += f[j-1]`
- 时间复杂度 O(mn)，空间 O(n)

**题解代码（Python）**：
```python
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        f = [1] * n
        for i in range(1, m):
            for j in range(1, n):
                f[j] += f[j - 1]
        return f[n - 1]
```

## 2. 最小路径和（64）

**难度**：中等

**题目描述**：给定一个包含非负整数的 `m x n` 网格 `grid`，请找出一条从左上角到右下角的路径，使得路径上的数字总和为最小。说明：每次只能向下或者向右移动一步。

**原题链接**：https://leetcode.cn/problems/minimum-path-sum/

**解题思路**：
- `f(i, j) = min(f(i-1, j), f(i, j-1)) + grid[i][j]`，首行首列只能单方向累加
- 原地修改 grid 或用一维滚动数组
- 时间复杂度 O(mn)，空间 O(n)

**题解代码（Python）**：
```python
class Solution:
    def minPathSum(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        f = [0] * n
        f[0] = grid[0][0]
        for j in range(1, n):
            f[j] = f[j - 1] + grid[0][j]
        for i in range(1, m):
            f[0] += grid[i][0]
            for j in range(1, n):
                f[j] = min(f[j], f[j - 1]) + grid[i][j]
        return f[n - 1]
```

## 3. 最长公共子序列（1143）

**难度**：中等

**题目描述**：给定两个字符串 `text1` 和 `text2`，返回这两个字符串的最长 公共子序列 的长度。如果不存在公共子序列，返回 `0`。一个字符串的 子序列 是指这样一个新的字符串：它是由原字符串在不改变字符的相对顺序的情况下删除某些字符（也可以不删除任何字符）后组成的新字符串。

**原题链接**：https://leetcode.cn/problems/longest-common-subsequence/

**解题思路**：
- 二维 DP：`f(i, j)` 为 text1 前 i 个字符与 text2 前 j 个字符的 LCS 长度
- 尾字符相等：`f(i, j) = f(i-1, j-1) + 1`；不等：`max(f(i-1, j), f(i, j-1))`
- 可用两行滚动优化空间
- 时间复杂度 O(mn)，空间 O(mn) 或 O(min(m,n))

**题解代码（Python）**：
```python
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        m, n = len(text1), len(text2)
        f = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if text1[i - 1] == text2[j - 1]:
                    f[i][j] = f[i - 1][j - 1] + 1
                else:
                    f[i][j] = max(f[i - 1][j], f[i][j - 1])
        return f[m][n]
```

## 4. 编辑距离（72）

**难度**：中等

**题目描述**：给你两个单词 `word1` 和 `word2`，请返回将 `word1` 转换成 `word2` 所使用的最少操作数。你可以对一个单词进行如下三种操作：插入一个字符；删除一个字符；替换一个字符。

**原题链接**：https://leetcode.cn/problems/edit-distance/

**解题思路**：
- 经典二维 DP：`f(i, j)` 为 word1 前 i 个字符变成 word2 前 j 个字符的最少操作数
- 边界：`f(i, 0) = i`、`f(0, j) = j`
- 转移：尾字符相等则 `f(i, j) = f(i-1, j-1)`；否则 `1 + min(f(i-1, j), f(i, j-1), f(i-1, j-1))`（删除 / 插入 / 替换）
- 时间复杂度 O(mn)，空间 O(mn)

**题解代码（Python）**：
```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        m, n = len(word1), len(word2)
        f = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(m + 1):
            f[i][0] = i
        for j in range(n + 1):
            f[0][j] = j
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if word1[i - 1] == word2[j - 1]:
                    f[i][j] = f[i - 1][j - 1]
                else:
                    f[i][j] = min(f[i - 1][j],      # 删除
                                  f[i][j - 1],      # 插入
                                  f[i - 1][j - 1]) + 1  # 替换
        return f[m][n]
```

## 5. 最长回文子串（5）

**难度**：中等

**题目描述**：给你一个字符串 `s`，找到 `s` 中最长的回文子串。

**原题链接**：https://leetcode.cn/problems/longest-palindromic-substring/

**解题思路**：
- 中心扩展法：回文一定有中心，共有 `2n - 1` 个中心（n 个单字符中心 + n-1 个双字符间隙中心）
- 从每个中心向两侧扩展，遇到字符不等即停止，记录扩展出的最长回文的起止下标
- 相比区间 DP `f[i][j]`（时间空间均为 O(n²)），中心扩展法空间只需 O(1)
- 时间复杂度 O(n²)，空间 O(1)

**题解代码（Python）**：
```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        n = len(s)
        start, end = 0, 0

        def expand(l, r):
            while l >= 0 and r < n and s[l] == s[r]:
                l -= 1
                r += 1
            return l + 1, r - 1  # 回到最后一次合法的位置

        for center in range(n):
            l1, r1 = expand(center, center)      # 奇数长度
            if r1 - l1 > end - start:
                start, end = l1, r1
            l2, r2 = expand(center, center + 1)  # 偶数长度
            if r2 - l2 > end - start:
                start, end = l2, r2
        return s[start:end + 1]
```

**题解代码（Java）**：
```java
class Solution {
    public String longestPalindrome(String s) {
        int n = s.length(), start = 0, end = 0;
        for (int center = 0; center < n; center++) {
            int[] odd = expand(s, center, center);      // 奇数长度
            if (odd[1] - odd[0] > end - start) { start = odd[0]; end = odd[1]; }
            int[] even = expand(s, center, center + 1); // 偶数长度
            if (even[1] - even[0] > end - start) { start = even[0]; end = even[1]; }
        }
        return s.substring(start, end + 1);
    }

    private int[] expand(String s, int l, int r) {
        while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) {
            l--;
            r++;
        }
        return new int[]{l + 1, r - 1};
    }
}
```

**题解代码（Go）**：

    start, end := 0, 0

        for l >= 0 && r < n && s[l] == s[r] {
            l--
            r++
        }
        return l + 1, r - 1
    }

            start, end = l, r
        }
        if l, r := expand(center, center+1); r-l > end-start { // 偶数长度
            start, end = l, r
        }
    }
    return s[start : end+1]
}
