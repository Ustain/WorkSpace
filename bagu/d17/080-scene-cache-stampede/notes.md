# 80. 热点失效击穿 · 口试

## 1. 现象

某个商品/用户接口突然打满 DB，Redis 该 key 不存在或刚过期，DB 单行锁/CPU 升。和雪崩（大面积）、穿透（乱 id）不同。

## 2. 止血

- 网关对该 URL/id 限流。
- 本地缓存强行托几秒。
- 互斥锁只放一个回源，其他返回旧值或稍等。
- 必要时把热 key 设成永不过期并后台刷新。

## 3. 定位

- 监控热 key、DB 相同 SQL。
- 是否 TTL 整点到期、是否发布清了缓存、是否活动开始。

## 4. 根治

- 逻辑过期 + 异步刷新；热 key 多级缓存。
- 库存分桶打散热点。
- TTL 随机对雪崩有用，对单 key 击穿不够。

## 5. 60 秒口述

> 击穿是单个热 key 过期，流量打到同一行。止血：限流、单飞回源、本地缓存。根治：逻辑过期后台刷、热点分桶。别当成穿透去调布隆。
