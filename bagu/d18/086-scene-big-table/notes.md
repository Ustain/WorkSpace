# 86. 大表治理 · 口试

## 1. 现象

单表亿级，查询慢、DDL 不敢做、备份恢复长、磁盘涨。先确认是真需要分片还是索引/历史数据问题。

## 2. 止血

- 热点查询加缓存、强制走索引、限流报表。
- 只读历史切归档库。
- 禁止 `SELECT *` 和大 offset。

## 3. 定位

- 冷热比、有无合适索引、是否宽表、是否历史订单从不访问。
- 主键是否 UUID 导致页分裂。

## 4. 根治（由易到难）

1. 归档/分区表按时间。
2. 索引与字段治理、冷列拆表。
3. 读写分离。
4. 最后水平分库分表（题 23）。

DDL 用 gh-ost。在线改主键极痛，尽量一开始选对。

## 5. 60 秒口述

> 大表先归档和索引，不要先分片。止血是限流和缓存热点。根治按时间分区或冷热分离，分库分表是最后一步。DDL 走在线工具。主键尽量递增。
