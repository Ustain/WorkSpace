# Change: 新增客服工单趋势分析工具

## Why

客服主管每天要面对大量工单，但当前只能人工翻列表，难以快速判断「哪类问题在变多」和「哪些异常必须盯」。0111 测评要求在 50 条工单上落地一套可运行的分析方案，把精力从翻单变成看趋势和行动建议。

## What Changes

- 新增离线分析工具：读取 `tickets.json`，按时间、类型、优先级、处理时长、满意度、渠道等维度聚合。
- 新增异常检测：识别类型突增、重复问题、高优未解决、处理积压、低满意度、资金风险等信号，并给出判断依据。
- 新增主管可读输出：生成 HTML Dashboard 与 Markdown 报告，包含摘要、图表、异常清单和行动建议。
- 新增 README：说明分析维度、关键发现、复现方式和 AI 工具使用情况。

## Capabilities

### New Capabilities

- `ticket-trend-analysis`: 工单数据加载、多维趋势统计、可解释异常检测、主管报告与可视化输出。

### Modified Capabilities

- 无。当前仓库尚无既有规格。

## Impact

- 新增 Python 分析脚本、报告模板、单测和测评交付文档。
- 无外部服务依赖；不引入数据库或 Web 后端。
- 输入为测评附件 50 条工单；输出为本地报告文件。
